# T046 — client replica: storage, delta application, read queries (`crpg-net`)

## Task / Crate(s) / Purpose

Sole crate: `crpg-net`, Phase 5 (M5), plan row `docs/IMPLEMENTATION_PLAN.md:248`.
Build `ReplicaWorld`, the engine-neutral client copy of one filtered v2
session: it applies decoded lane-0 delta frames and published snapshots, in
order, refusing every frame that breaks the T027b wire rules (N1–N9), and
answers the read queries T047 needs (ADR-0033, `docs/adr/0033-godot-bridge.md:525-529`).
Owner per E012 (`tasks/E012-binary-crate-naming.md:72`).

## Exact contract

Status: **proposed, not approved.** Sole crate `crpg-net` plus its two docs and
one ADR. Prerequisites met on this branch: T021 (`protocol_v2`, `codec_v2`),
T024 (`SnapshotBody`, `reassembly::Publication`). **T046 needs no T027b code**:
it consumes T027b's rules, not `InterestView`, and its tests never import
`crpg_net::interest`. T046 and T027b may land in either order.

### Decision

- **D1. One module `replica`, one type `ReplicaWorld`.** Path
  `crates/crpg-net/src/replica.rs`. The spec's "no mutating methods except
  `apply_delta`" (`docs/CRPG_ENGINE_SPEC.md:175`) is read as the apply family:
  `apply_delta` and `apply_snapshot` are the only `&mut self` methods. The
  conformance test double (`crates/crpg-net/tests/conformance.rs:271`) is not
  reused or replaced; it stays an independent oracle.
- **D2. Storage is one `Vec<ReplicaEntity>`, strictly ascending `NetId`.**
  T047 makes one bulk ascending pass into packed arrays
  (`docs/adr/0033-godot-bridge.md:271`), so a slice is the natural query.
  Because delta enters are always above every stored id (D6), a delta enter
  is a push at the end; lookup and removal are a binary search. No
  `HashMap`/`HashSet`, in the module or its tests.
- **D3. A row is presence plus `Option<HealthFact>`.** `None` is unknown, never
  zero (N4). `dead` lives only inside `HealthFact`: the `Died` notice does not
  set it, because death travels with the health grant (`tasks/T027b.md:366-369`)
  and notices are not state (N8). The turn is one `Option<TurnFact>`: outer
  `None` means no turn fact yet; `active: None` means no disclosed actor (N7).
  Both reuse the T024 types unchanged (`protocol_transfer.rs:285-312`).
- **D4. `apply_delta` takes a decoded `&protocol_v2::DeltaFrame`;
  `apply_snapshot` takes a `&reassembly::Publication`.** The bridge decodes
  (`docs/adr/0033-godot-bridge.md:152`), so codec faults stay code 52 and
  replica faults code 53. Whole values, not loose fields, so a caller cannot
  pair one page's ops with another page's sequence, or one body with another
  transfer's cursor. `Publication` is what the T024 pool releases
  (`crates/crpg-net/src/reassembly.rs:277-282`).
- **D5. Strict sequence law, no in-band reset.** A frame is accepted only when
  `event_seq` equals the next expected value. A restart at 1 after progress is
  an error. T022's lane-0 narrowing reset returns
  `GrantUpdate::RebindRequired` (`crates/crpg-server/src/host.rs:209-212`,
  `:840-857`), on which the QUIC adapter fences the connection
  (`crates/crpg-server/src/quic.rs:1267-1283`). The restarted stream therefore
  belongs to a new session, and the caller builds a new `ReplicaWorld` for it.
  That is how "that path empties the replica first" (N9) is met. T047's player
  is a snapshot session, which narrows by transfer with no restart
  (`host.rs:840-843`), and grants never narrow in the slice
  (`docs/adr/0033-godot-bridge.md:229`).
- **D6. Reuse is caught by a high-water mark.** `high_water` is the largest
  `NetId` ever stored. A delta enter at or below it is a reuse. A snapshot row
  at or below it that is not live just before the snapshot is a reuse. This
  enforces N3 with no retired-id table. It also relies on one rule beyond
  N1–N9: ids are minted in rising order and only when disclosed (T027b item 4
  and D7; today's host `plan_map`, `host.rs:2197-2225`). See "What T027b and
  T027c must keep". Delivery is an in-order prefix, so every id below the
  client's high-water mark was once entered on this replica, and one that is
  not live has been retired.
- **D7. Every op is validated, notices and events included.** Each `NetId` an
  op names must be live at that point. The host names an id in history only
  when it is mapped and present (`net_if`, `host.rs:2323`), and the T027b page
  puts history after enters and before removals (`tasks/T027b.md:126-128`).
  So a legal page never names a dead id, and N1 is enforced once, here.
  `Receipt.epoch` is the only epoch a delta carries; it must equal the
  replica's epoch.
- **D8. Live rows may reach `2 * MAX_VISIBLE_ENTITIES` mid-page.** A T027b
  page puts all enters before all removals (`tasks/T027b.md:335-340`) and may
  split at any op boundary (N8). A swap of 1,024 entities therefore briefly
  holds 2,048 rows, between frames or within one. A 1,024 cap would refuse a
  legal page. This is a client bound, not wire.
- **D9. Atomicity: validate and apply on a working copy, then commit.** `Err`
  leaves the replica equal to a pre-call clone. Cloning at most 2,048 small
  rows per frame is the simple, correct implementation, and it is the one
  expected. Any other approach must meet item 3 exactly.
- **D10. One closed error enum, every variant fatal, small payloads.**
  Payloads name the offending id or sequence for `last_error`. No variant is
  recoverable: ADR-0033 maps any `Err` to fatal code 53 `REPLICA_REJECTED`
  and never skips (`docs/adr/0033-godot-bridge.md:342`, `:346-349`). The
  replica itself stays usable after `Err` (tests continue); fencing is the
  bridge's policy.
- **D11. v2 only.** T047 binds a V2 session (`docs/adr/0033-godot-bridge.md:90`).
  There is no v1 entry point: N9's "V1 receives no notices" is vacuous here,
  and a later V1 client is a `Legacy`-wrapping adapter in its own task.
- **D12. No allocation in queries, no events kept.** The bridge already holds
  the decoded frame, so it collects events and receipts itself
  (`docs/adr/0033-godot-bridge.md:527-528`). `ended()` is the bridge's.
  `apply_delta` returns `()`: T048 diffs `net_ids` between revisions itself
  (`docs/adr/0033-godot-bridge.md:517`).

### Interface (`crates/crpg-net/src/replica.rs`)

```rust
use core::fmt;

use crate::protocol::{NetId, SessionEpoch, MAX_DELTA_OPS, MAX_VISIBLE_ENTITIES, SEQ_LAST};
use crate::protocol_transfer::{HealthFact, TurnFact};
use crate::protocol_v2::DeltaFrame;
use crate::reassembly::Publication;

/// Largest live row count, reached only mid-page (D8). Not a wire bound.
pub const MAX_REPLICA_ENTITIES: usize = 2 * MAX_VISIBLE_ENTITIES;

/// One live entity. Rows are strictly ascending by `net_id`.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ReplicaEntity {
    /// The client-scoped replica id.
    pub net_id: NetId,
    /// The last disclosed health fact; `None` while unknown, never zero.
    pub health: Option<HealthFact>,
}

/// Why a frame or publication was refused. Every variant is fatal to the
/// session (ADR-0033 code 53).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ReplicaError {
    /// `frame.lane != LANE_COMBAT`.
    WrongLane { got: u8 },
    /// `frame.ops.len() > MAX_DELTA_OPS`.
    TooManyOps { got: usize },
    /// `event_seq` is not the next expected one, or is above `SEQ_LAST`.
    EventSeq { expected: u64, got: u64 },
    /// An op names an id that is not live at that point.
    UnknownEntity { entity: NetId },
    /// An `EntityEnter` names a live id.
    DuplicateEntity { entity: NetId },
    /// An id at or below the high-water mark that is not live (N3, D6).
    ReusedEntityId { entity: NetId },
    /// More than `MAX_REPLICA_ENTITIES` rows, or a body over
    /// `MAX_VISIBLE_ENTITIES`.
    TooManyEntities,
    /// A `Receipt` carries another epoch.
    WrongEpoch,
    /// A body row is not strictly above the previous row (duplicates too).
    SnapshotOrder { entity: NetId },
    /// `cursor` is below the last applied `event_seq` or above `SEQ_LAST`.
    SnapshotCursor { min: u64, got: u64 },
}
impl fmt::Display for ReplicaError { /* Behaviour item 15 */ }
impl std::error::Error for ReplicaError {}

/// The engine-neutral client replica of one filtered v2 session. One per
/// session; not `Serialize`, no restore constructor (a saved replica would
/// restore stale authorization, `tasks/T027c.md:22-23`).
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ReplicaWorld {
    epoch: SessionEpoch,
    entities: Vec<ReplicaEntity>, // strictly ascending net_id
    turn: Option<TurnFact>,
    next_event_seq: u64,          // 1 at `new`
    server_tick: u64,             // 0 at `new`
    high_water: u64,              // largest NetId ever stored; 0 at `new`
}

impl ReplicaWorld {
    pub fn new(epoch: SessionEpoch) -> Self;
    pub fn epoch(&self) -> SessionEpoch;
    /// Every live row, ascending `NetId`; at most `MAX_REPLICA_ENTITIES`.
    pub fn entities(&self) -> &[ReplicaEntity];
    /// One live row by binary search; `None` for any id not live.
    pub fn entity(&self, net_id: NetId) -> Option<&ReplicaEntity>;
    pub fn len(&self) -> usize;
    pub fn is_empty(&self) -> bool;
    /// The last applied turn fact; `None` before any in this replica.
    pub fn turn(&self) -> Option<&TurnFact>;
    /// The only `event_seq` `apply_delta` accepts next. `u64::MAX` after a
    /// publication at `SEQ_LAST`: nothing more is accepted.
    pub fn next_event_seq(&self) -> u64;
    /// The last accepted frame's `server_tick` or publication's `base_tick`.
    pub fn server_tick(&self) -> u64;
    pub fn apply_delta(&mut self, frame: &DeltaFrame) -> Result<(), ReplicaError>;
    pub fn apply_snapshot(&mut self, publication: &Publication) -> Result<(), ReplicaError>;
}
```

`src/lib.rs` gains `pub mod replica;` after `pub mod reassembly;` and one
crate-doc sentence. Every public item, field and variant is documented
(`#![warn(missing_docs)]`, `src/lib.rs:2`). No existing item changes.

Terms, for one call: **live** means present in the working rows at that point
of the call. **next** means `next_event_seq`. **last** means
`next_event_seq - 1`.

### Behaviour

1. **Construction.** `new(epoch)`: no rows, `turn() == None`,
   `next_event_seq() == 1`, `server_tick() == 0`, high-water 0. The epoch
   never changes. No other constructor exists: no `Default`, no restore, no
   `serde`.
2. **Delta precedence.** `apply_delta` checks in this order and reports the
   first fault: (a) `frame.lane != LANE_COMBAT` → `WrongLane { got: lane }`;
   (b) `ops.len() > MAX_DELTA_OPS` → `TooManyOps { got: len }`; (c)
   `event_seq != next || event_seq > SEQ_LAST` →
   `EventSeq { expected: next, got: event_seq }`; (d) ops in frame order per
   item 6, each validated against the working state left by the ops before
   it; the first faulty op's error is returned.
3. **Atomicity.** `Err` from either function changes nothing: the replica
   equals a pre-call clone. `Ok` commits rows, turn, `next_event_seq`,
   `server_tick` and high-water together. No input panics, overflows or
   indexes out of bounds.
4. **Sequence law.** On `Ok`, `next_event_seq = event_seq + 1` and
   `server_tick = frame.server_tick`, including for an empty `ops` frame and
   a frame of only notices, events or receipts. Nothing is buffered or
   skipped. A gap, duplicate, reorder, rewind, restart at 1, `0`, or a value
   above `SEQ_LAST` is `EventSeq`. A tick that goes backwards is not an error
   (area clocks need not match, `tasks/T027b.md:149-150`).
5. **Fresh replica.** The first accepted delta of a new replica has
   `event_seq == 1`, unless a publication came first (item 12).
6. **Op effects.** Error checks per op run in the order listed.

   | Op (`protocol_v2::DeltaOp`) | Checks | Effect |
   |---|---|---|
   | `Legacy(EntityEnter { e })` | live → `DuplicateEntity{e}`; `e ≤ high_water` → `ReusedEntityId{e}`; `len == MAX_REPLICA_ENTITIES` → `TooManyEntities` | push `{ e, health: None }`; `high_water = e` |
   | `Legacy(EntityLeave { e })` | not live → `UnknownEntity{e}` | remove the row and its health |
   | `Legacy(Despawned { e })` | not live → `UnknownEntity{e}` | exactly as `EntityLeave` |
   | `Legacy(Spawned { e })`, `Legacy(Died { e })` | not live → `UnknownEntity{e}` | none |
   | `Legacy(Health { e, health, max_health, dead })` | not live → `UnknownEntity{e}` | `health = Some(HealthFact { health, max_health, dead })` |
   | `Legacy(Turn { active, round })` | `active == Some(a)`, `a` not live → `UnknownEntity{a}` | `turn = Some(TurnFact { active, round })` |
   | `Legacy(Receipt { epoch, .. })` | `epoch != self.epoch.0` → `WrongEpoch` | none |
   | `ActionResolved { actor, target, .. }` | actor not live → `UnknownEntity{actor}`; then target | none |
   | `TurnStarted { actor, .. }` | actor not live → `UnknownEntity{actor}` | none |
   | `EncounterEnded { .. }` | — | none |

   Health is stored verbatim; no relation among `health`, `max_health` and
   `dead` is checked. An enter of an entity, then any op naming it, in the
   same frame is legal; the reverse order is `UnknownEntity`.
7. **Health (N4).** An entered row has `health: None` until a `Health` op.
   `Health` replaces all three fields. No op clears health. `dead: true`
   never removes a row. `Died` changes no health, including `dead`.
8. **Turn (N6, N7).** `Turn` replaces the whole fact. `active: None` is stored
   as-is. No delta op clears or edits the turn: not `EncounterEnded`, not the
   removal of the active actor. `turn().active` may therefore name an id that
   is no longer live; callers pair it with `entity`.
9. **Removal (N2).** `EntityLeave` and `Despawned` have the same state
   effect. After either, every op naming the id is `UnknownEntity`, and an
   enter of it is `ReusedEntityId`.
10. **Bounds (D8).** After any op, `len() <= MAX_REPLICA_ENTITIES`. Stored
    state is the rows, one optional turn and three `u64`s: no retired-id
    table, no events, receipts, history or buffered frames. Transient work is
    one working copy per call.
11. **Snapshot precedence.** `apply_snapshot(p)` checks in this order: (a)
    `p.cursor < last || p.cursor > SEQ_LAST` →
    `SnapshotCursor { min: last, got: p.cursor }`; (b)
    `p.body.entities.len() > MAX_VISIBLE_ENTITIES` → `TooManyEntities`; (c)
    rows in body order: an id not strictly above the previous row's id →
    `SnapshotOrder{id}`; otherwise an id `≤ high_water` that is not live in
    the pre-call replica → `ReusedEntityId{id}`; (d)
    `p.body.turn.active == Some(a)` with `a` not in the body →
    `UnknownEntity{a}`. `p.transfer` is not read.
12. **Snapshot replacement (N5).** On `Ok`, the rows become exactly the body's
    rows in body order (already ascending), each `health` verbatim, `None`
    included. The turn becomes exactly `p.body.turn`, `None` included. A live
    id missing from the body is gone, with no op. `next_event_seq =
    p.cursor + 1`, `server_tick = p.base_tick`, and `high_water` becomes the
    larger of itself and the body's last id. A cursor equal to `last` and a
    cursor ahead of it (frames the host discarded at staging,
    `host.rs:1632-1635`) are both legal. Rule (a) is the pool's
    `BehindReplica` cursor rule (`reassembly.rs:660`), so every publication
    the pool releases passes it. The body ids passing item 11(c) is a T027b
    obligation (item 12 there: live keys keep ids, new keys mint new ones).
13. **Queries.** `entities()` is strictly ascending with no duplicates.
    `entity(n)` is `Some` exactly for ids in `entities()`. `len` and
    `is_empty` agree with it. `turn`, `next_event_seq` and `server_tick`
    return committed state. No query allocates or mutates. An unknown,
    retired or never-issued id gives the same answer, `None`.
14. **Determinism and no derived authority.** Equal epochs and equal accepted
    call sequences give equal replicas (`PartialEq`). The replica reads only
    its arguments. It uses no `World`, clock, RNG, I/O or config, derives no
    presence, health, turn, ownership or legality, and adds no dependency.
15. **Display.** Exact strings, payloads in decimal with `NetId::get`:
    `WrongLane at replica: got {got}`; `TooManyOps at replica: got {got}`;
    `EventSeq at replica: expected {expected}, got {got}`;
    `UnknownEntity at replica: {entity}`;
    `DuplicateEntity at replica: {entity}`;
    `ReusedEntityId at replica: {entity}`; `TooManyEntities at replica`;
    `WrongEpoch at replica`; `SnapshotOrder at replica: {entity}`;
    `SnapshotCursor at replica: min {min}, got {got}`.

### N1–N9: behaviour and error

| Rule (`tasks/T027b.md:573-593`) | Enforced by | Wire break → error |
|---|---|---|
| N1 no op names an id before its enter or a published body | item 6 liveness on every id-bearing op, item 11(d) | `UnknownEntity` |
| N2 a removal is exactly one op; nothing names the id afterwards | items 6, 9 | `UnknownEntity`; re-enter `ReusedEntityId` |
| N3 no reuse; new epoch is an empty replica; no linking | `new`, D6, items 6 and 11(c); receipt epoch | `ReusedEntityId`, `WrongEpoch` |
| N4 absent health is unknown; `Health` replaces whole; entity stays after death | items 7, 13 | `UnknownEntity` for `Health` on a non-live id; absence is legal |
| N5 snapshot replaces all incl. turn; missing id is gone | items 11, 12 | `SnapshotCursor`, `TooManyEntities`, `SnapshotOrder`, `ReusedEntityId`, `UnknownEntity` |
| N6 delta never clears health or turn; last value until replaced | items 7, 8 | none: no op clears, by construction |
| N7 `active: None` = no disclosed actor | items 6, 8 | `UnknownEntity` only for a `Some` non-live actor |
| N8 pages split at any op boundary; `Spawned`/`Died` are notices | per-frame application with no buffering (item 4), D8 bound, item 6 | `EventSeq` for a lost, repeated or reordered frame |
| N9 V1 gets no notices; lane-0 reset empties first | D11 (no v1 entry point); D5 (reset is a new session and a new replica) | `EventSeq` if the restart is fed to the old replica |

### What T027b and T027c must keep

- **K1.** T027b item 4 and D7: ids are minted in rising order, once, and only
  for keys being disclosed. D6 depends on it. Breaking it turns legal pages
  into fatal `ReusedEntityId`, which is loud, not a silent desync.
- **K2.** History ops name only ids mapped for the viewer, placed after enters
  and before removals (T027b D6, C3, C4). D7 depends on it.
- **K3.** A lane-0 restart at `event_seq` 1 is delivered only to a new
  session, never into a live one (D5). This is true today through
  `RebindRequired` and the adapter fence.

No change to T027b's text is needed: K1–K3 restate its items.

### What T047 must adapt to

- Call `apply_delta` with every decoded lane-0 frame, in order; any `Err` is
  fatal 53. Event-op and receipt faults are replica faults too (D7).
- Build arrays from `entities()`. `health: None` gives `health_known = 0`;
  `dead` comes from `HealthFact` only. A `Died` event does not set `dead()`.
- `turn().and_then(|t| t.active)` may name a non-live id (item 8). Treat a
  missing proxy as no highlighted actor, not as an error.
- `observed_tick` may be taken from `server_tick()`
  (`docs/adr/0033-godot-bridge.md:309-310`).
- `entities()` may hold up to 2,048 rows mid-page (D8). This never happens in
  the slice, which has no removals of this kind.
- `apply_snapshot` has no caller in the slice: a `Transfer` entry is fatal 54.
  The first task that narrows a live session feeds pool `Publication`s here.
  On `RebindRequired` it builds a new `ReplicaWorld`.

### Wire impact

**None.** No protocol version, tag, field, constant, code, fixture or golden
changes. The module consumes existing `protocol_v2::DeltaFrame`,
`protocol::DeltaOp`, `protocol_transfer` and `reassembly::Publication`
values; it encodes, decodes and mints nothing. `MAX_REPLICA_ENTITIES` is a
client bound, not wire. What this crosses: a new public surface needs an ADR
(`docs/architecture/crpg-net.md:39-40`), under the next free number at
implementation time. The implementer files it from this contract. No
`crpg-server` change, and no host call site.

### Tests (new `crates/crpg-net/tests/replica.rs`)

No new dependency. Inputs are literal `DeltaFrame`s and `Publication`s
(`TransferId::new(1)`), plus bytes from the existing encoders. Expected
values are hand-written literals or the truth state of a test-local `Script`.
`Script` is a server stand-in with its own id counter (rising from 1), its
own visible set (`BTreeMap<u64, Option<HealthFact>>`), turn and `event_seq`.
It emits pages in the T027b layout: enters, notices and events naming live
ids, healths, turn, removals. It chunks them at op boundaries of its
choosing and can emit a `Publication`. The oracle is the script's state,
never a second applier and never production code. **`InterestView` is not
used**: T027b has not landed, and generating inputs from it would block
T046 on it. Every rejection asserts the replica equals its pre-call `clone()`.

- **R1 (1, 13). Construction.** All queries on `new(e)` give their item 1
  values. *Control:* one frame `{seq 1, tick 9, [Enter 1]}` gives `len 1`,
  `next_event_seq 2`, `server_tick 9`.
- **R2 (6, 9). Enter, health, leave, despawn.** A literal 4-frame run with
  the exact `entities()` after each frame. *Control per op:* the same run
  without that op leaves exactly that one fact unchanged.
- **R3 (7, N4). Unknown is not zero.** After enter, `health == None`. After
  `Health {0, 10, false}`, `Some` with 0. A never-entered id gives
  `entity == None`. *Control:* the zero row and an untouched row compare
  unequal.
- **R4 (7). Death.** `Health { dead: true }` keeps the row. `Died` leaves
  `health` unchanged, for a `None` row and for an alive `Some` row.
  *Control:* a `Health` with `dead: true` is what sets it.
- **R5 (6). Notices, events, receipts are inert.** Each of `Spawned`, `Died`,
  `ActionResolved`, `TurnStarted`, `EncounterEnded` and an own-epoch
  `Receipt` over live ids changes only `next_event_seq` and `server_tick`.
  *Controls:* each id-bearing op with a non-live id gives `UnknownEntity`
  with that id: `ActionResolved` with the actor unknown, then with the actor
  live and the target unknown. A foreign-epoch `Receipt` gives `WrongEpoch`.
- **R6 (6, 8, N6, N7). Turn.** These cases are stored verbatim: a live
  active; `active: None`; an active entered earlier in the same frame. An
  active entered later in the same frame is `UnknownEntity`, and so is a
  removed one. After the actor leaves, and after `EncounterEnded`, `turn()`
  is unchanged. *Control:* a new `Turn` replaces it.
- **R7 (2c, 4, 5). Sequence.** Frames 1, 2 (empty ops), 3 (notices only) are
  accepted. Each case below gives the exact `EventSeq { expected, got }`
  and leaves the replica unchanged: a first frame at 2; a gap 1 then 3; a
  duplicate; a rewind; a restart at 1 after 3; `0`; `SEQ_LAST + 1`. After
  a publication at `SEQ_LAST`, the frame `u64::MAX` gives
  `{ u64::MAX, u64::MAX }`. A backwards tick is accepted. *Control:* after
  each fault the right frame applies, and a new replica accepts the
  restarted stream from 1.
- **R8 (2a, 2b). Shape.** Lane 1 gives `WrongLane{1}`. 257 ops give
  `TooManyOps{257}`. *Control:* a 256-op lane-0 frame applies.
- **R9 (6, D6, N3). Duplicate and reuse.** Entering a live id is
  `DuplicateEntity`. Leaving 2 then entering 2 is `ReusedEntityId{2}`. With
  high-water 5, entering a never-seen 4 is `ReusedEntityId{4}`. *Controls:*
  entering 6 applies; a new replica accepts entering 2.
- **R10 (10, D8). Bounds.** 2,048 enters across 8 frames apply; the 2,049th
  is `TooManyEntities`. A swap page over 1,024 live rows has 1,024 enters
  then 1,024 leaves, in 256-op frames. It reaches `len 2048` after frame 4
  and ends at 1,024 with only the new ids. *Control:* at 2,048, a leave then
  an enter in one frame applies.
- **R11 (12, N5). Replacement.** Mid-epoch the replica is {1, 2, 3} with a
  turn on 3. A body {1, 3, 4} with health only on 4 and `turn: None` gives
  exactly those rows. Row 1 loses its old health, because the body
  replaces. Row 2 is gone, and any later op on 2 is `UnknownEntity`. The
  turn becomes `None`, and `server_tick == base_tick`. *Control:* the next
  delta at `cursor + 1` applies; entering 2 is `ReusedEntityId`; entering 5
  applies.
- **R12 (11a, 12). Cursor.** Each cursor below sets `next_event_seq` to
  cursor + 1. Cursor 0 on a new replica gives 1. After frames 1..3: cursor 3
  gives 4, and cursor 7 gives 8, skipping frames. Cursor 2 is
  `SnapshotCursor{3, 2}`, and `SEQ_LAST + 1` is refused. *Control:* frame
  `cursor + 1` applies, while `cursor + 2` and `cursor` are `EventSeq`.
- **R13 (11). Snapshot faults.** Each of these gives the named error and
  leaves the replica unchanged: 1,025 rows (`TooManyEntities`); [3, 2] or
  [2, 2] (`SnapshotOrder{2}`); a retired id, or a never-seen id below the
  high-water mark (`ReusedEntityId`); an active outside the body
  (`UnknownEntity`). Combined faults report in item 11 order. *Controls:*
  1,024 ascending rows apply; ids above the high-water mark apply; an
  active inside the body applies.
- **R14 (3). Atomicity.** All ten variants are provoked on a non-empty
  replica, which then equals its clone each time. One frame is
  `[Enter 9, Leave 1, Health 2, Turn{9}, Enter 9]`: it fails on op 5 and
  changes nothing. *Control:* the same frame without op 5 applies, and every
  one of the four effects is visible.
- **R15 (4, N8). Split pages.** One `Script` page is applied three ways: as
  one frame, as one-op frames, and in random chunks. Rows and turn are equal
  all three ways. After the enter frames of the split run, the rows are live
  with `health: None`. *Control:* the unsplit page.
- **R16 (14). Scripted convergence.** 2,000 `Script` steps drawn from
  `crpg_core::DeterministicRng::from_seed(46).stream("replica")`. The steps
  include enters, healths, leaves, despawns, notices, events, turn changes,
  swaps at the cap and publications, some with skipped frames. Two replicas
  chunked differently equal the script's truth after every page and each
  other after every page. *Control:* a run of identical inputs is equal
  under `PartialEq`, and changing one health value makes them unequal.
- **R17 (corrupt and drop).** Each of these makes the run fail: dropping a
  frame (`EventSeq`), swapping two frames (`EventSeq`), moving a `Health`
  before its enter (`UnknownEntity`), and duplicating a removal
  (`UnknownEntity`). Altering one health value is accepted by the replica
  but fails the truth comparison, which proves the oracle is not vacuous.
  *Control:* untouched pages converge.
- **R18 (Wire impact).** A literal page goes through
  `codec_v2::encode_delta`, then `decode_delta`, then `apply_delta`, and
  equals the struct path. A body goes through `encode_body` and
  `decode_body`, then `Publication`, and equals the struct path. A frame
  with `event_seq u64::MAX` round-trips the codec and is refused here.
  *Control:* `--test codec`, `--test conformance` and `--test events_v2`
  pass unmodified.
- **R19 (15). Errors.** Every `Display` string is exact, one example per
  variant. `ReplicaError: Copy + std::error::Error`.

## Adjudication

Both drafts were checked against source. A was right far more often. B's
frame-epoch check cites a field that does not exist. Both missed the
mid-page bound.

| Point | Winner | Why |
|---|---|---|
| Owner and type | Both | One `ReplicaWorld` in `crpg-net` (E012). |
| Storage | A | A sorted `Vec` gives T047 a slice; B's `net_ids()` allocates a `Vec` per call. |
| Row content | A | B's sticky `dead` set by `Died` contradicts N8 and `tasks/T027b.md:366-369`. |
| Epoch check | Neither | B's `WrongEpoch` reads "frame epoch bytes", but `DeltaFrame` has none (`protocol_v2.rs:67-77`). A checks nothing. Only `Receipt.epoch` exists, and it is checked. |
| Reset at `event_seq` 1 | B, for a corrected reason | A's in-band reset and `fresh` flag tie the replica to the host page layout, and they make a re-delivered frame 1 wipe the replica. The restart is `RebindRequired`, and the adapter fences on it (`quic.rs:1267-1283`). So it comes on a new session, and the caller builds a new replica. B's "`WrongEpoch` fires" is wrong. `EventSeq` fires instead. |
| Sequence errors | A's payloads, B's single variant | One `EventSeq { expected, got }` covers A's four variants, with the same precision for tests. |
| Event-op ids | A | B's "hidden actor nameable in history" is false: `net_if` requires a mapping and the present grant (`host.rs:2323`). |
| Reuse | A, simplified | The high-water mark is kept, A's fresh-page exemption is dropped (D5), and the check is extended to snapshot bodies. B has no check. |
| Live bound | Neither | Both cap at 1,024 while a frame is applied. A T027b page puts enters before removals, so a legal swap needs 2,048 (D8). |
| Snapshot input | Neither | A's `(cursor, &body)` and B's `(body, base_seq, base_tick)` both let a caller mix fields. `&Publication` is what the pool releases. |
| Body order | B | Reject non-ascending input. `decode_body` already guarantees ascending order, so rejecting costs one pass, while A's sort would accept input the wire can never produce. |
| Cursor rule | A | `cursor >= last` matches the pool's `BehindReplica` (`reassembly.rs:660`). B's `next = base_seq + 1` had no lower bound. |
| `server_tick` | B | T047 builds `observed_tick` from it (ADR-0033:309-310). There is no regression error (B's Q2). A's collision worry is met by storing the `base_tick`. |
| Return value | A | B's `AppliedDelta` has no consumer. |
| Query shape | A | `entity()` returning `Option<&ReplicaEntity>` replaces B's `Option<Option<_>>` and A's ambiguous `health()`. A's `active`, `round` and `contains` are dropped as redundant. |
| Atomicity | Neither exactly | Both pin clone-equality. A's two-pass staging is replaced by a working copy (D9), which is simpler for an implementer and cheap at 2,048 rows. |
| ADR | A | Required by `docs/architecture/crpg-net.md:39-40`. B said none was needed. |
| Routing | A | Not H-filter. B's "per-client filtering change" does not apply: the replica filters nothing. |
| `NotSnapshotPeer` | Dropped | B's own Q1: a dead variant. |
| v2 only, oracle | Both | `InterestView` is not used at all, so T046 is not blocked on T027b code. |

Open questions settled: A1 (no, D5), A2 (validate, D7), A3 (payloads, D10),
A4 (reject unordered), A5 (the host's empty-narrowing frame does not concern a
snapshot session; the lane-0 path fences, D5), B1 (dropped), B2 (no tick
error), B3 (names out, per D41b).
