## Task
Skip the Rust gates (`cargo fmt`, `clippy`, `test`) in CI's `check` jobs for
pull requests that change only documentation, while both `check` contexts
still report.

## Crate(s)
None. Touches `.github/workflows/ci.yml` only (S-set: reviewed by the user
before merge).

## Purpose
Both `check` jobs run a full workspace `cargo test` on every pull request.
Measured on PR #29's run (38875484668): Windows 7.0 min, Linux 4.1 min; every
other job takes under a minute. Documentation-only pull requests, which the
agent-team plan makes frequent (bookkeeping, task records, plans), pay that in
full for no information. With the skip they finish in about a minute.

## Change
In the `check` job:
- `actions/checkout` fetches full history, so the change can be diffed against
  the pull request's base.
- A `scope` step lists the changed paths with `git diff --name-only
  --no-renames <merge-base>...HEAD` and sets `rust=false` only when every path
  is under `docs/` or `tasks/`, is Markdown at the repository root, or is a
  `crates/*/AGENTS.md`. Anything else, an empty base, or any error means every
  gate runs (the step fails closed).
- `rust-cache`, `fmt`, `clippy` and `test` run only when `rust == 'true'`.
- Pushes to `master` and the weekly schedule always run every gate.

Design constraints, each recorded in the workflow comment:
- **Required checks.** The `master-protection` ruleset requires
  `check (ubuntu-latest)` and `check (windows-latest)`. A workflow-level
  `paths-ignore` would leave them pending for ever, so the job always runs and
  skips steps instead.
- **Renames.** `--no-renames` lists both sides of a move, so moving a file out
  of `crates/` counts as a code change.
- **Inline logic.** A classification script in the tree would be judged by
  the pull request it judges; inline in the workflow, a fork cannot change it
  (the guard job rejects fork edits to `.github/workflows/**`).
- **Nothing allowlisted is compiled or read.** On 2026-10-16 no build or test
  read anything under `docs/` or `tasks/` or any `.md` file. A future
  `include_str!` of an allowlisted path must take that path off the list.

report both `check` contexts green with the Rust steps skipped.

slowest test (T097).
