## Task

Give `crpg-net` the first-class malicious-client suite the spec asks for:
"oversized packets, malformed frames, intents for entities not owned, intents
at illegal times, flooding, replay of old packets, requesting entities
outside the interest set. Every one of these must produce a clean rejection
and a log line, never a panic" (`docs/CRPG_ENGINE_SPEC.md:1488`). The plan
splits it: T042 is the wire level in `crpg-net`, "host-level cases live in
T041" (`docs/IMPLEMENTATION_PLAN.md:242`; T041 is `crpg-testkit`, `:241`).

The wire level is the server's byte boundary: the eight decoders a client's
bytes reach (lane 0 v1–v4, the `0x81`/`0x82` transfer upstream, the `0x91`
resume request, the `0xA1` movement intent). Each is tested today in its own
suite with its own fixtures and its own selection of hostile inputs; no
suite treats them as one surface, none sends one wire's frame to another
wire's decoder, none corrupts every byte with every value, and none checks
that what a decoder accepts re-encodes stably, which the host's replay cache
relies on (`crates/crpg-server/src/host.rs:1588–1590`, `:1666–1668`). T042
adds that suite as one table-driven file, corrects three doc comments and
one architecture invariant that misstate the decode order, and writes the
index that maps each of the spec's seven classes to the test that proves it
at the wire level, or to T041.

## Readings
Design decisions this contract makes. Each needs approval with the contract.

1. **The surface is the eight server-facing decoders.** A malicious client
   controls only the bytes it sends; in `crpg-net` those reach
   `codec::decode_intent` (`crates/crpg-net/src/codec.rs:190`),
   `codec_v2::decode_intent` (`crates/crpg-net/src/codec_v2.rs:277`),
   `codec_v3::decode_intent` (`crates/crpg-net/src/codec_v3.rs:241`),
   `codec_v4::decode_intent` (`crates/crpg-net/src/codec_v4.rs:223`),
   `codec_transfer::decode_up` (`crates/crpg-net/src/codec_transfer.rs:432`),
   `transfer_v3::decode_up` (`crates/crpg-net/src/transfer_v3.rs:610`),
   `codec_resume::decode_request` (`crates/crpg-net/src/codec_resume.rs:103`)
   and `movement_v4::decode_intent` (`crates/crpg-net/src/movement_v4.rs:228`).
   The pools, replicas and `MoveOutbox` are the client's receivers: their
   input is the server's bytes, not a client's. *Rejected:* both drafts'
   pool and replica replay cases (draft A M-2/M-3, draft B B7–B12), which
   test a hostile server, not a hostile client (Question 2).
2. **A matrix over all eight, not a gap-fill.** Every hostile class runs
   against every wire from one table, so a new server-facing decoder is one
   new row (D-4). Some cells repeat a per-codec test (for example
   `crates/crpg-net/tests/codec.rs:449`); that is the price of one place that
   shows the whole boundary. *Rejected:* draft A's three missing cells only
   (v2 `Health.dead`, two pool replays): the first is a downstream decoder,
   the other two are client receivers (Reading 1).
3. **Stateless decoders have no replay, timing, ownership or interest
   case.** A decoder is a function of one byte slice, so "replay of old
   packets", "intents at illegal times", "entities not owned" and "outside
   the interest set" have no byte-level form beyond a zero id. Their
   wire-level parts that exist in `crpg-net` are already proven and are
   indexed, not re-tested (D-1): the rate bucket the host uses
   (`crates/crpg-net/src/sim.rs:157`, `crates/crpg-server/src/host.rs:60`),
   `SessionFence` (`crates/crpg-net/src/resume.rs:74`),
   `InterestView::entity` (`crates/crpg-net/src/interest.rs:215`;
   `crates/crpg-server/src/host.rs:4350–4356`) and the T018c double's
   matrix (`crates/crpg-net/tests/conformance.rs:391–1019`). The rest is
   T041's. *Rejected:* draft B's per-decoder replay tests (pass by
   construction) and both drafts' re-tests of fence and outbox.
4. **The code's decode order is the contract; three comments and one
   invariant are corrected to it.** Every decoder checks each field as it
   reads it: `seq` range and nonzero `actor` before the body tag
   (`crates/crpg-net/src/codec.rs:204–207`, `crates/crpg-net/src/codec_v2.rs:291–294`).
   The architecture invariant (`docs/architecture/crpg-net.md:154–157`),
   the v1 module doc (`crates/crpg-net/src/codec.rs:6–16`) and the v1/v2
   `decode_intent` docs (`crates/crpg-net/src/codec.rs:187–189`,
   `crates/crpg-net/src/codec_v2.rs:273–276`) put those checks after the
   trailing-byte check, which would make `seq` 0 with an unknown tag
   `UnknownMessage` (receipt code 5) instead of the `Malformed` (6) the code
   returns (`crates/crpg-server/src/host.rs:3959–3964`). The v2 module doc
   already says it right (`crates/crpg-net/src/codec_v2.rs:27–31`). X9 pins
   the code. *Rejected:* changing the code to match the doc (it would move
   frozen v1 receipt bytes).
5. **Corruption is exhaustive, and acceptance must be stable.** For each of
   the 17 pinned frames, every byte is replaced by every other value
   (128,265 inputs); the result must be a refusal, or a frame whose canonical
   re-encoding is the corrupted bytes themselves, except inside ULID text,
   where core accepts case and `I`/`L`/`O` aliases
   (`crates/crpg-core/src/ulid.rs:111–122`). `postcard` accepts non-minimal
   varints (postcard 1.1.3, `de/deserializer.rs` `try_take_varint_u64`),
   but no pinned frame has a varint byte followed by `0x00` except an
   `actor` before tag 0, where the shifted tag is refused, so no single-byte
   corruption reaches that leniency. A seeded corpus adds multi-byte noise
   under the weaker rule the host needs: a decoded value re-encodes, and the
   re-encoding decodes back to itself (`crates/crpg-server/src/host.rs:1588–1590`).
   *Rejected:* `proptest` (a new `crpg-net` dev-dependency, needs asking,
   `AGENTS.md` "Do not add dependencies"; and it samples where this
   enumerates); draft B's ten-value `header_faults` (samples the values X6–X8
   enumerate).
6. **Stability is checked through the encoder, not `PartialEq`.**
   `ResumeRequest` holds a `ResumeProof`, which by trap never gains
   `PartialEq` (`crates/crpg-net/src/protocol_resume.rs:94–97`,
   `crates/crpg-net/AGENTS.md:98–106`); comparing re-encoded bytes works for
   all eight wires and is exactly what the host compares.
7. **The "log line" at this level is the refusal and its fixed text.**
   `crpg-net` does no I/O (`docs/architecture/crpg-net.md:260–263`); no
   workspace crate depends on a logging crate (`tracing` is in `Cargo.lock`
   only through `quinn`, `quinn-proto` and `quinn-udp`), and in
   `crpg-server` only `src/main.rs` prints. Every refusal here is a `CodecError` whose `Display` is one of
   six fixed texts (`crates/crpg-net/src/codec.rs:68–79`), and the host maps
   it to a receipt code (`crates/crpg-server/src/host.rs:3959–3964`). X14
   pins the texts. Writing a log line is Question 1.
8. **T042 fixes nothing in a decoder.** If a case fails against unchanged
   source, the implementer stops and reports it with the failing input; the
   fix is its own contract (a pool or codec fix has its own rules,
   `crates/crpg-net/AGENTS.md` T026p4 entry). *Rejected:* draft B's
   conditional Part B (a source fix folded into a test task).

## Interface
**Production code: none.** No public item, signature, variant, constant or
`Display` text of `crpg-net` changes; the only `src/` edits are the comment
lines of D-3. Everything below is test-local, in
`crates/crpg-net/tests/malicious_client.rs`, with these exact shapes (names
of private helpers may not change: the review and later tasks cite them).

```rust
//! T042: the wire-level malicious-client suite (spec §16.2, §19.2 #21).
//! Every server-facing decoder, every hostile class, one table. No clock,
//! no thread, no I/O, no unseeded RNG, no `HashMap`/`HashSet`, no float.

/// One server-facing decoder with its own encoder (Reading 1).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum Wire { V1, V2, V3, V4, T81, T82, R91, A1 }

/// Table order; every "for each wire" loop uses it.
const WIRES: [Wire; 8] = [Wire::V1, Wire::V2, Wire::V3, Wire::V4,
                          Wire::T81, Wire::T82, Wire::R91, Wire::A1];

impl Wire {
    /// 1, 2, 3, 4, 0x81, 0x82, 0x91, 0xA1.
    fn first_byte(self) -> u8;
    /// Index of the lane byte: 17, 17, 17, 17, 1, 1, 1, 17.
    fn lane_at(self) -> usize;
    /// The lane byte: 0, 0, 0, 0, 2, 2, 3, 1.
    fn lane(self) -> u8;
    /// Decode with this wire's decoder; on `Ok(v)`, re-encode `v` with this
    /// wire's encoder. An encoder error on a decoded value panics with the
    /// wire, the input bytes and the error (the test fails: W-12, W-13).
    fn verdict(self, bytes: &[u8]) -> Verdict;
}

#[derive(Debug, Clone, PartialEq, Eq)]
enum Verdict {
    /// The decoder refused the bytes with this error.
    Refused(CodecError),
    /// The decoder accepted them; the canonical re-encoding of the value.
    Accepted(Vec<u8>),
}

/// One pinned valid frame (the table in W-1).
struct Fixture { name: &'static str, wire: Wire, bytes: Vec<u8>, tag_at: usize }

/// The 17 fixtures of W-1, in its table order, each built by its wire's
/// encoder from the value in that table (never from hand-written bytes).
fn fixtures() -> Vec<Fixture>;

/// `bytes` with `bytes[at]` replaced by `value`; every other byte, the valid
/// remainder after `at` included, unchanged.
fn with_byte(bytes: &[u8], at: usize, value: u8) -> Vec<u8>;

/// `bytes` followed by `0x00` up to `len` bytes (`len >= bytes.len()`).
fn padded(bytes: &[u8], len: usize) -> Vec<u8>;

/// W-13's rule: `Refused(_)`, or `Accepted(c)` with `verdict(&c) == Accepted(c)`.
fn stable(wire: Wire, bytes: &[u8]) -> bool;

/// Marsaglia xorshift64 (shifts 13, 7, 17), wrapping `u64` arithmetic.
struct XorShift64(u64);
impl XorShift64 { fn next(&mut self) -> u64; }   // state ^= state << 13; state ^= state >> 7; state ^= state << 17; returns state
const SEED: u64 = 0x5EED_0000_0000_0042;
```

## Behaviour

from the cited code; the implementer does not adjust one to make a test
pass (S-1).

`wire.verdict(bytes) == Accepted(bytes)` (each is canonical).

W-2. **Short inputs, exhaustively.** For every wire and every input of at
most two bytes (the empty input, all 256 one-byte inputs, all 65,536
two-byte inputs): `[]` → `Refused(Malformed)`; `[b]` → `Malformed` if `b`
is the wire's first byte, else `UnsupportedVersion`; `[b, c]` →
`UnsupportedVersion` if `b` is not the first byte; otherwise, for `V1`–`V4`
and `A1` (lane at 17) `Malformed`, and for `T81`, `T82`, `R91` (lane at 1)
`WrongDirection` if `c` is not the wire's lane, else `Malformed`. The `0x81`,
`0x82` and `0x91` decoders test emptiness explicitly
(`crates/crpg-net/src/codec_transfer.rs:436–438`), the others fail the
version read; no input this short reaches a tag. *Tests:* X2.

W-3. **Oversize is refused first.** The cap of all eight decoders is 4,096
bytes (`MAX_INTENT_FRAME_BYTES`, `crates/crpg-net/src/protocol.rs:58`;
`MAX_UP_FRAME_BYTES` and `MAX_RESUME_FRAME_BYTES` equal it,
`crates/crpg-net/src/protocol_transfer.rs:48`,
`crates/crpg-net/src/protocol_resume.rs:40`), checked before anything else.
For every wire: `[0xFF; 4097]` → `FrameTooLarge` (cap beats version);
`[0xFF; 4096]` → `UnsupportedVersion`; for each of its fixtures,
`padded(f, 4096)` → `Malformed` (trailing bytes) and `padded(f, 4097)` →
`FrameTooLarge`. *Tests:* X3.

W-4. **Every truncation is `Malformed`.** For every fixture and every
`n < len`, `verdict(&f[..n]) == Refused(Malformed)`: a prefix keeps every
header value, so the version, lane and tag checks pass and the first read
past the end fails. A v2–v4 ULID body (`crates/crpg-net/src/codec_v2.rs:153–159`)

length, which is within it); a v1 ability string is taken whole, with no
bound before the read (`crates/crpg-net/src/codec.rs:136–143`), so a prefix
inside it fails that read, also `Malformed` (W-10 (a), D-2). *Tests:* X4.

W-5. **Trailing bytes are `Malformed`.** For every fixture, `f ++ [t]` for
`t` in `0x00, 0x01, 0xFF` → `Malformed`. *Tests:* X5.

W-6. **A foreign first byte is `UnsupportedVersion`.** (a) Every fixture,

## Tests

each test's control is named. No clock, no sleep, no `#[should_panic]`
(a panic anywhere is a failure). Every assertion message names the wire,
the fixture and the input bytes (`{:02X?}`), so a failure is reproducible
from the log alone.

  encoder's bytes equal the literal of W-1 (built from `H(v)`, `EPOCH`, the
