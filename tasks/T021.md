## Interface — exact approval gate

Retain existing `protocol`/`codec` v1 public APIs and byte fixtures unchanged.
Propose separate `protocol_v2`/`codec_v2` modules rather than changing the
meaning of existing `PROTOCOL_VERSION = 1` or its encode/decode functions.
The readiness ADR must pin these exact exports and signatures, version byte
2, all new discriminants/field order, event correlation and bounded strings,
plus version-selection behavior. No concrete new event tag is allocated until
T020's list is accepted. v2 may carry the old projection vocabulary unchanged
in meaning, but it does not serialize `SimEvent` directly.

Approval must include a field-by-field disclosure table: every referenced
identity and outcome/damage fact allowed or suppress the entire event; still
send separately permitted state. Per-client event sequencing preserves approved
relative order without exposing authoritative queue gaps. No roll/DC leak via
outcomes, error text or cache. No open component payload bag.

## Behaviour

Version is selected explicitly by caller/approved peer negotiation, never
guessed from tags. A v1 peer still exchanges byte-identical v1. Sending v2 to
a v1 decoder returns `UnsupportedVersion`; placing a new tag inside an otherwise
valid v1 envelope returns `UnknownMessage`. These are different tests; the
former alone does not prove unknown-variant rejection. Unsupported inputs are
not ignored and do not mutate replicas/World. Preserve v1 error precedence.

New encode/decode bounds precede allocation from hostile lengths. Freeze new
codes/tags explicitly rather than deriving evolving serde enum indices.
Retain two-tier limits, lane-0 window/seq/cache semantics and per-field omission.
Capture ordered v2 events in an independent oracle: T018c's event-multiset
comparison alone is insufficient to prove richer-history ordering.

### Modules and exact API

Keep current root module exports unchanged; add `protocol_v2`, `codec_v2`,
`projection_v2` (module exports, no root glob).

```rust
// protocol_v2
pub const PROTOCOL_VERSION: u8 = 2;
pub const DELTA_TAG_ACTION_RESOLVED: u8 = 8;
pub const DELTA_TAG_TURN_STARTED: u8 = 9;
pub const DELTA_TAG_ENCOUNTER_ENDED: u8 = 10;
// Re-export unchanged v1 value types, not v1's version constant:
pub use crate::protocol::{IntentFrame, IntentBody, NetId, SessionEpoch,
                          ReceiptStatus, RejectionCode};
pub struct DeltaFrame {
    pub lane: u8,
    pub server_tick: u64,
    pub event_seq: u64,
    pub ops: Vec<DeltaOp>,
}
pub enum DeltaOp {
    Legacy(crate::protocol::DeltaOp),
    ActionResolved { actor: NetId, target: NetId, ability: Ulid,
                     outcome: String, damage: u32 },
    TurnStarted { actor: NetId, round: u64 },
    EncounterEnded { encounter: Ulid, round: u64 },
}

// codec_v2: CodecError is re-exported from codec; same six variants.
pub fn encode_intent(frame: &IntentFrame) -> Result<Vec<u8>, CodecError>;
pub fn decode_intent(bytes: &[u8]) -> Result<IntentFrame, CodecError>;
pub fn encode_delta(frame: &DeltaFrame) -> Result<Vec<u8>, CodecError>;
pub fn decode_delta(bytes: &[u8]) -> Result<DeltaFrame, CodecError>;

// projection_v2
pub enum EventCandidate {
    Spawned { entity: Option<NetId>, disclose: bool },
    Despawned { entity: Option<NetId>, disclose: bool },
    Died { entity: Option<NetId>, disclose: bool },
    ActionResolved { actor: Option<NetId>, target: Option<NetId>,
        ability: Option<Ulid>, outcome: Option<String>, damage: Option<u32> },
    TurnStarted { actor: Option<NetId>, round: Option<u64> },
    EncounterEnded { encounter: Option<Ulid>, round: Option<u64> },
}
pub enum ProjectionError { TooManyEvents, InvalidOutcome, StringLimit }
pub fn project_events(candidates: &[EventCandidate])
    -> Result<Vec<protocol_v2::DeltaOp>, ProjectionError>;
```

New structs/enums derive Debug, Clone, PartialEq, Eq; no serde derives for wire
or candidates. ProjectionError implements Error/Display, no source; Display
`<VariantName> at projection/events`. Reuse protocol's lane, sequence, wire and
policy constants by qualified reference; do not create divergent numeric copies.
`Legacy` is only a Rust wrapper; it contributes **no extra tag** on the wire.
This avoids duplicating eight state/receipt variant definitions.

### Frozen wire layout and codec rules

v2 intent is identical to v1 except its first byte is 2. v2 delta header is
`version:u8=2, lane:u8=0, server_tick:u64, event_seq:u64, op_count:u64` using the
existing postcard primitive conventions. Tags 0..7 and every following payload
byte are identical to v1; new tag payloads follow this exact order:

| Tag | Payload |
|---|---|
| 8 | actor:u64, target:u64, ability:ULID-text, outcome:UTF8-text, damage:u32 |
| 9 | actor:u64, round:u64 |
| 10 | encounter:ULID-text, round:u64 |

ULID-text is a postcard length-prefixed string, encoded as 26 uppercase ASCII
characters; decoder retains core's accepted aliases then re-encodes canonically.
Outcome is T020's exact five symbolic forms (custom decimal 0..255, no leading
zeros). Round accepts the full u64 wire range; producer widens its actual round.
No raw EntityId, sim sequence, internal operation id, roll, DC, margin or grants
are transmitted. Receipt payload remains exactly epoch/lane/seq/tick/status.

Keep 4096-byte intent, 65536-byte delta, 256-op, 256-byte string and 4096-byte
byte-field maxima. A new decoder reads string length as a bounded integer and
checks <=256 **before** allocating/copying or checking available body bytes;
then checks body availability/UTF-8, then semantic ULID/outcome validity. It may
borrow slices first. New v2 code must not copy v1's owned-string-before-check
implementation. Do not modify v1's compatibility/error behavior to achieve this.

Decode uses left-to-right wire order: whole-frame cap first; version; lane;
header scalar reads; op-count cap before vector growth; each tag then fields;
finally reject trailing bytes. A failure prevents examining later fields.
Nonzero ids and sequence ranges are checked when read, matching actual v1
codec behavior, not an imagined whole-message postvalidation pass. New outcome
length errors are LimitExceeded, bad UTF-8/truncated/body/ULID/outcome are
Malformed; unknown op or receipt tags/codes are UnknownMessage. Receipt foreign
lane is WrongDirection. Intent/receipt seq retain 1..=u64::MAX-1. As in the
actual v1 codec, delta event_seq accepts the full u64 representation; host
delivery policy issues 1..=u64::MAX-1 and refuses exhaustion without wrapping.
Empty op lists are allowed. Encode checks lane, count,
then op semantics in order and final frame length; an encoder must not return
partial bytes. No allocation from an untrusted op-count capacity hint.

Calling a codec is explicit version selection: v1 refuses byte 2; v2 refuses
byte 1. No auto detection, negotiation, downgrade or default preference. Private
primitive helpers may be shared only if all existing v1 tests/bytes/precedence
stay intact. Do not patch the first byte and pass unchecked v2 tags through v1.

### Projection and disclosure contract

T022 maps actual ordered HistoryEnvelopes into EventCandidates. Each Some value
means the host has independently authorized disclosure of **that field** for
this viewer/generation; None means forbidden or identity unavailable. Unknown
grants are None/false. These plain values are not authentication credentials;
ordinary clients never construct authoritative projection inputs.

| History fact | Required disclosure |
|---|---|
| Spawned/Despawned/Died | entity mapping and explicit corresponding cause grant |
| ActionResolved | both mappings, authored ability id, symbolic outcome, reported damage |
| TurnStarted | actor mapping and round/turn-start fact |
| EncounterEnded | authored encounter identity and terminal round/end fact |

`project_events` checks at most 256 input candidates, then visits in input order.
If any required field/grant is absent it omits the whole event, without inspecting
hidden optional payload values further. Otherwise check outcome byte bound then
symbolic validity, and append exactly one op. Returns no partial output on error.
Never fills hidden values with zero or emits placeholders. Output is an ordered
subsequence; never sort by actor, tag or NetId, nor deduplicate equal events.
Same tick and repeated logical turns retain their journal order.

Projection is stateless: no reader/ack, id minting, live replica or history
retention here. Host assigns per-client **frame** event_seq after suppression
and chunking, starting at 1; it must not reuse authoritative history seq. A
suppressed-only page produces no frame and consumes no delivery sequence.
Independently permitted state ops are assembled by the host, so suppressing an
event does not suppress a Health/Turn update. EntityLeave for nondisclosable
removal is a separate host state-membership decision, not an inferred event.
Pre-removal mapping may project a permitted despawn notice; host retires its
actionable mapping before the next command regardless of event disclosure.

The codec itself checks shape, not entitlement. T027b/c later supply production
interest facts/grants. Replay identity, whole World hashes and internal queue
gaps are not replica verification oracles.

### Literal acceptance obligations

`tests/events_v2.rs` includes:

- `v1_and_v2_are_explicit`: every frozen v1 fixture still passes v1; equivalent
  old-vocabulary v2 bytes differ only in version. v1 on valid v2 reports
  UnsupportedVersion; separate correctly formed v1 frames with each tag 8, 9,
  10 report UnknownMessage. v2 refuses v1 and tag 11.
- `new_tags_have_literal_byte_oracles`: independently hand-encoded minimum and
  varint-boundary examples for all three tags, plus mixed old/new op order.
- `new_fields_are_bounded_before_allocation`: 256/257 string bytes, hostile
  length with absent body, 256/257 ops, exact frame cap/+1, zero ids, exhausted
  sequences, invalid custom outcomes, trailing/truncated/multifault frames.
- `field_by_field_suppression`: start with all fields permitted, remove each
  permission individually, verify total suppression; unrelated state update
  remains independently deliverable. Two peers receive different filtered views.
- `real_history_order_survives_projection`: create actual T020 HistoryWorld,
  perform action/death/turn/end/despawn transitions, read its public journal,
  explicitly map variants in test adapter, and compare ordered wire events to
  a hand-authored oracle. Dropping, duplicating or swapping a same-tick event
  must fail that oracle; no event-multiset comparison.
- `redelivery_is_byte_identical`: driver caches selected v2 encoded frames and
  recovers loss/duplicates without re-executing the public sim action; native
  complete-authority hash and journal prove exactly one mutation. Test driver
  marks these as fixture grants, not live auth/interest implementation.
