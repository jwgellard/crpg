# T146 — playable terminal combat (`crpg-cli`)

Approved direction: user, 2026-11-01 (wants a demo soon, to see things coming together). This is the first version a person plays rather than watches.

## Task / Crate(s) / Purpose
`crpg-cli` only. Add `crpgc play`: a fight in the terminal where a person chooses each move for their side and a simple rule plays the other side. It adds no rules: every choice comes from `crpg_sim::legal_actions` and every change goes through `crpg_sim::perform_action`.

## Interface
`crpgc play --campaign <dir> [--encounter <ulid>] [--side <name>] [--seed N]`

- `--encounter` defaults to the campaign's first encounter in document order.
- `--side` defaults to the side of the first combatant in the encounter; a name no combatant has is usage exit 2.
- `--seed` defaults to 0.
- New private module `crates/crpg-cli/src/play.rs`. Reuse the name lookup and output helpers of `demo.rs` and the bind glue of `combat_apply.rs`; move shared code rather than copy it. `main.rs` gets parsing, dispatch and the usage line only.

## Behaviour
1. Print the same header as `crpgc demo`.
2. On a turn of the player's side: print round, acting combatant and health of everyone, then a numbered list of `legal_actions` in the order returned, by ability name and target name, plus `q` to quit. Read one line from stdin.
3. A number in range performs that action and prints the same block `crpgc demo` prints. Anything else prints one line naming the valid range and asks again, with no change to the world.
4. On any other side's turn: perform the first attack in `legal_actions` order that targets a living opponent; if there is none, the first legal action. Print the same block.
5. When the fight ends, print the `crpgc demo` summary and exit 0. `q` prints `Quit.` and exits 0. End of stdin behaves as `q`.

## Errors
Usage errors exit 2 with one stderr line. A campaign that fails to load, or has no encounter, exits as `crpgc replay` does for an invalid campaign.

## Test
In new `crates/crpg-cli/tests/play.rs`, as subprocess tests that pipe stdin, in the style of `tests/demo.rs`, over `combat_basic` and `combat_srd`:
- a stdin of repeated `1` plays to the end: exit 0, summary present, exactly one winner;
- the same stdin and seed twice gives byte-identical stdout; a run that differs only by `--seed` is allowed to differ, and at least one of seeds 0..=9 must give different stdout from seed 0;
- `0`, an out-of-range number and `abc` each print the range line and leave the following output the same as without that line;
- `q` and empty stdin exit 0 with `Quit.` and no summary;
- every listed option on a player turn performs without error, checked by choosing the last option on each turn in one run;
- final health in the summary equals that reached by driving `crpg_sim` directly with the same choices in the test;
- unknown `--side`, unknown `--encounter`, a missing `--campaign` and a non-number `--seed` each exit 2.
