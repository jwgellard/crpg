## 2. `tools/lint/deps.py` (exact edit)

Insert one row immediately after the `"crpg-net"` row of `ALLOWED`:

```python
    # T023s/ADR-0024: the real QUIC transport. It sees only crpg-net's public
    # byte protocol, Transport trait and queue caps. No row lists it except
    # the None-rows above it (server, cli, testkit, godot), so crpg-net and
    # everything below cannot reach tokio/quinn/rustls through it.
    "crpg-net-quic":  ({"crpg-net"}, set()),
```

Nothing else in `deps.py` changes (unless §5 is approved). In particular:
- no existing row changes;
- `crpg-server`, `crpg-cli`, `crpg-testkit` and `crpg-godot` keep `None`,
  so they may already take `crpg-net-quic`;
- `crpg-net`'s set stays `{"crpg-core", "crpg-data", "crpg-sim"}`, so
  `crpg-net` can never depend on `crpg-net-quic`.

**Why `{"crpg-net"}` and not `{"crpg-core", "crpg-net"}`.** No item in
T023's interface or tests names a `crpg-core` type:
- the hello and welcome carry raw bytes;
- the queue caps come from `crpg_net::sim::QueueCaps`;
- the test frames are `EndTurn` intents and receipt deltas built with
  `crpg_net::codec`, and neither needs `Ulid`.

A row is a ceiling, so the smallest one the design needs is the right one.
A later task that needs `crpg-core` adds it under review (open question 11
in T023).

## 3. `tools/lint/test_deps.py` (new tests; nothing existing edited)

Append one class. The fixture trees use the real `ALLOWED` table, as every
existing case does:

```python
class TestNetQuicPlacement(TreeCase):
    """ADR-0024: the QUIC transport sits above crpg-net, never below it."""

    def test_net_quic_may_depend_on_net(self):
        self.assertEqual(self.all_violations({
            "crpg-net": [],
            "crpg-net-quic": ["crpg-net"],
        }), [])

    def test_net_quic_may_not_depend_on_sim(self):
        """The transport is a byte pipe; simulation stays out of its graph."""
        violations = self.all_violations({
            "crpg-sim": [],
            "crpg-net-quic": {"dev-dependencies": ["crpg-sim"]},
        })
        self.assertTrue(
            any("crpg-net-quic -> crpg-sim" in v for v in violations), violations
        )

    def test_net_may_not_depend_on_net_quic(self):
        """The Q12 guarantee: protocol consumers never inherit the I/O graph."""
        for section in ("dependencies", "dev-dependencies"):
            with self.subTest(section=section):
                violations = self.all_violations({
                    "crpg-net": {section: ["crpg-net-quic"]},
                    "crpg-net-quic": [],
                })
                self.assertTrue(
                    any("crpg-net -> crpg-net-quic" in v for v in violations),
                    violations,
                )

    def test_server_may_depend_on_net_quic(self):
        """T023b's edge is already legal through crpg-server's None row."""
        self.assertEqual(self.all_violations({
            "crpg-net": [],
            "crpg-net-quic": ["crpg-net"],
            "crpg-server": ["crpg-net", "crpg-net-quic"],
        }), [])
```

## 4. Documentation (doc-only, every file signed)

- **`docs/adr/0024-separate-crpg-net-quic-crate.md`** (new, from the
  template; every placeholder replaced).
  - Title: "Real QUIC transport in a separate `crpg-net-quic` crate".
  - Status: **Accepted**, citing the user's Q12 answer recorded in
    `tasks/T023.md` "Decisions — 2026-10-04 (UTC)" and this contract's
    approval.
  - Context: the T023 exact contract placed QUIC in a `crpg_net::quic`
    module under a scoped no-I/O exception. A lint can police where code
    sits, but every dependant of `crpg-net` would still link tokio, quinn
    and rustls.
  - Decision:
    - the transport lives in `crpg-net-quic`, with `ALLOWED` row
      `{"crpg-net"}`;
    - `crpg-net` keeps its no-I/O, no-thread, no-clock rule with **no

    - only crates that depend on `crpg-net-quic` link the QUIC graph;
    - the D23 pins are approved for `crpg-net-quic`, not `crpg-net`
      (subject to T023 revised question 12).
  - Alternatives: the module plus a lint (rejected by the user); a `quic`
    cargo feature (an untested or always-on configuration under ADR-0012's
    default-features gates).
  - Consequences:
    - `crpg-net` dependants other than `crpg-server` and its consumers stay
      I/O-free;
    - T023b takes a path edge, not the QUIC crates;
    - each later lane splits into a `crpg-net` wire task and a
      `crpg-net-quic` transport task.
  - Acceptance: "not yet run" until T023's completion record.

## 5. Conditional: I/O-crate manifest ban (only if T023 open question 14 is approved)

If approved, add to `deps.py`:

```python
# ADR-0024: crates that must stay free of sockets, async runtimes and TLS.
# A direct manifest entry for any of these, in any section (target tables
# included, renamed entries resolved), is a violation. Transitive edges are
# covered by the ALLOWED table: none of these crates may reach crpg-net-quic.
IO_FREE_CRATES = {"crpg-core", "crpg-data", "crpg-rules", "crpg-sim", "crpg-net"}
IO_CRATES = {"tokio", "quinn", "quinn-proto", "quinn-udp", "rustls", "ring", "mio", "socket2"}
```

Add a `check_io_free(external)` function, shaped like `check_godot`. It
prints `VIOLATION <crate> -> <dep> (io-free, <label>)` and is called in
`main()` and in `TreeCase.all_violations` after `check_godot`. Add to the
module docstring's check list. Self-tests:
- `crpg-net` with `tokio` in `[dependencies]` is a violation;
- the same in `[dev-dependencies]` is a violation;
- `[target.'cfg(windows)'.dependencies]` with `rustls` is a violation;
- a renamed `rt = { package = "tokio" }` is a violation;
- `crpg-net-quic` with all eight crates passes;
- `crpg-server` with `tokio` passes.

Nothing today trips it (crpg-net, core, data, rules and sim name none of
these). If question 14 is declined, this section is omitted entirely and
