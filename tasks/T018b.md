# T018b — Simulated transport (`crpg-net`)

## Task

Implement the deterministic in-memory simulated transport over T018a's lane-0
protocol: bounded duplex queues, injected time, and reproducible fault
schedules. `crpg-net`-only single-crate task, ordered after T018a.

## Crate(s)

`crpg-net` (only).

## Purpose

Prove admission, backpressure, retry, and ordering behavior without a real
network: reliable-ordered lane-0 delivery with loss/dup/reorder injection,
exact ingress/egress accounting, and per-lane seq/cache semantics that later
host and QUIC work can consume unchanged.

## Interface (exact additions; T018a shapes unchanged)

```rust
// crates/crpg-net/src/sim.rs
pub struct SimClock(pub u64); // millis, injected only; never SystemTime
impl SimClock { pub fn now(&self) -> u64; pub fn advance(&mut self, dt_ms: u64); }

pub struct QueueCaps {
    pub per_peer_frames: usize, pub per_peer_bytes: usize,
    pub host_frames: usize, pub host_bytes: usize,
}
// v1 defaults from T018a operational policy; tightening-only overrides allowed.

pub struct RateCaps {
    pub frames_per_sec: u32, pub burst_frames: u32,
    pub bytes_per_sec: u32, pub burst_bytes: u32,
    pub fail_per_sec: u32, pub burst_fail: u32,
    pub fail_bytes_per_sec: u32, pub burst_fail_bytes: u32,
}

pub struct PeerState {
    pub epoch: [u8; 16], pub lane: u8, // LANE_COMBAT only in v1
    pub next_new_seq: u64,             // starts 1; SeqGap does not advance
    pub cache: Vec<(u64, Vec<u8>, ReceiptStatus)>, // last 256, canonical bytes
    pub fail_budget: TokenBucket, pub byte_budget: TokenBucket,
}

pub struct FaultSchedule {
    pub loss_every: Option<u64>, pub dup_every: Option<u64>,
    pub reorder_depth: usize, // 0 = none; bounded by queue caps
    pub seed: u64,            // DeterministicRng stream "net-fault", or counter
}

pub struct InMemoryTransport {
    pub fn new(caps: QueueCaps, rates: RateCaps, clock: SimClock) -> Self;
    pub fn add_peer(&mut self, epoch: [u8;16]) -> Result<PeerId, RejectionCode>;
    pub fn remove_peer(&mut self, peer: PeerId);
    pub fn send_to(&mut self, peer: PeerId, bytes: Vec<u8>) -> Result<(), RejectionCode>;
    pub fn recv_from(&mut self, peer: PeerId) -> Option<Vec<u8>>;
    pub fn tick(&mut self, faults: &FaultSchedule); // deterministic pump only
}
// All fallible paths map to T018a RejectionCode (QueueFull, RateLimited,
// ServerBusy, FrameTooLarge before decode). No sleep, no threads, no I/O.
// Retries and invalid attempts consume ingress budgets. Cached receipts share
// failure-response buckets and egress caps. Slow peers terminate with
// QueueFull, never silent reliable-event loss.
```

Window policy in v1 is 1 per lane per peer (stop-and-wait at the driver level);
the transport itself supports gap detection and cached-retry delivery so a
larger window later is policy + conformance, not a wire break. Sequence
exhaustion (`u64::MAX`) requires a new epoch, never wrap. New epoch resets
numbering; reattachment not supported in v1.

## Behaviour

- Reliable-ordered logical lane 0: loss injection is recovered by
  retry/dedup in the model; intentionally unreliable delivery is never used
  for combat commands. Reorder is bounded and deterministic from `seed`.
- Ingress accounting happens before decode/cache lookup; egress accounting
  covers normal deltas and failure responses. Checked arithmetic throughout;
  no reservation from hostile lengths.
- Time comes only from `SimClock` or a test-supplied `u64`; World tick never
  drives replenishment (pause cannot freeze or flood budgets).
- Peer table bounded (8 for the proof; excess `add_peer` → `ServerBusy`).
  Cache bounded (256 + ≤2 MiB per peer per lane; beyond → `StaleSeq` on
  evicted retry). Snapshot reassembly at most 1 in flight per peer, ≤32
  chunks, 5 s injected deadline → `SnapshotExpired`, then full resync.
- Test-double host policy (net-local, not the real host): authenticated peer +
  matching epoch + per-lane seq/cache + 200-tick freshness window +
  mapping/visibility table + `perform_action` legality recheck immediately
  before execution. This double proves net/host boundary separation; passing
  here is not host integration passing.

## Test (`crates/crpg-net/tests/transport.rs`, net-local)

1. Backpressure: fill per-peer and host queues to both frame and byte caps;
   next send is `QueueFull` with no growth past either ceiling.
2. Rate: exhaust frame and byte buckets including retries/invalids; next
   admission is `RateLimited`; injected-time advance replenishes exactly.
3. Retry: drop a response, retry same canonical bytes → cached receipt, no
   re-execution, no new events/spend/draw; different bytes same seq →
   `SeqConflict` closes epoch; gap → `SeqGap` without advancing; evicted →
   `StaleSeq`.
4. Fault determinism: same seed + schedule → same delivery sequence on the
   same build; reorder bounded; no sleep or wall clock.
5. Freshness: observed tick older than 200 and future tick map to
   `StaleTick`/`FutureTick`; boundary 200 accepted, 201 rejected at fixed
   server tick (documents pause semantic).

Command that must pass: `cargo test -p crpg-net --test transport --locked`
