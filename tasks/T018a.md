# T018a — Lane-0 protocol v1 + codec (`crpg-net`)

## Task

Define and implement the versioned lane-0 combat wire plus its bounded
`postcard` codec and the local `Transport` trait. `crpg-net`-only
single-crate task (E004 child of T018). This is the first task that puts real
code in `crpg-net`, so it also opens the crate with its architecture doc and
`AGENTS.md`.

## Crate(s)

`crpg-net` (only).

## Purpose

Give every later transport and conformance test a stable, filterable,
extensible foundation: explicit version + lane, per-lane seq identity,
closed combat vocabulary, filtered replica vocabulary, versioned hard maxima,
and a codec that rejects malformed, unknown, oversized, and trailing-byte
inputs before allocation. Nothing here executes gameplay; it encodes and
decodes it.

## Read first

- Parent `tasks/T018.md` plus the Read-first list there.
- `crates/crpg-core` time/ULID/event contracts (Tick saturating, Ulid string
  serde, `(tick, seq)` queue order, payload-field bound per ADR-0011).
- `crates/crpg-sim` combat surface (`CombatAction`, `CombatError` precedence
  stays authoritative; net never copies it as gameplay logic).

## Interface (exact; changing this requires an ADR)

```rust
// crates/crpg-net/src/protocol.rs
pub const PROTOCOL_VERSION: u8 = 1;
pub const LANE_COMBAT: u8 = 0; // only implemented lane in v1; others rejected

pub const MAX_INTENT_FRAME_BYTES: usize = 4096;
pub const MAX_DELTA_FRAME_BYTES: usize = 65536;
pub const MAX_DELTA_OPS: usize = 256;
pub const MAX_WIRE_COLLECTION: usize = 256;
pub const MAX_WIRE_STRING_BYTES: usize = 256;
pub const MAX_WIRE_BYTES_FIELD: usize = 4096;
pub const MAX_SNAPSHOT_BYTES: usize = 1_048_576;
pub const MAX_VISIBLE_ENTITIES: usize = 1024;
pub const MAX_SNAPSHOT_CHUNKS: usize = 32;

// Session generation, host-issued. Replay isolation, not auth credentials.
pub struct SessionEpoch(pub [u8; 16]);

// Client-scoped replica id. Zero is never valid; never reused in one epoch.
#[derive(Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct NetId(u64); // new returns None on 0; get returns u64

#[derive(Clone, Copy, PartialEq, Eq)]
pub struct IntentFrame {
    pub epoch: [u8; 16],
    pub lane: u8,          // must equal LANE_COMBAT in v1
    pub seq: u64,          // 1..=u64::MAX-1; 0 and MAX rejected (see errors)
    pub observed_tick: u64,// advisory only; host policy validates
    pub actor: NetId,
    pub body: IntentBody,
}

#[derive(Clone, PartialEq, Eq)]
pub enum IntentBody {
    DeclareAction { ability: crpg_core::Ulid, target: NetId }, // discriminant 0
    EndTurn,                                                    // discriminant 1
}
// No other variants in v1. Unknown discriminants decode as UnknownMessage.
// Ability uses Ulid serde (canonical 26-char uppercase). No client-supplied
// costs, damage, ownership, or RNG state.

#[derive(Clone, PartialEq, Eq)]
pub struct DeltaFrame {
    pub lane: u8,          // LANE_COMBAT in v1
    pub server_tick: u64,
    pub event_seq: u64,    // per-client delivery order, gapless per peer
    pub ops: Vec<DeltaOp>, // 0..=MAX_DELTA_OPS, chunked at op boundaries
}

#[derive(Clone, PartialEq, Eq)]
pub enum DeltaOp {
    EntityEnter { entity: NetId },                                    // 0
    EntityLeave { entity: NetId },                                    // 1
    Spawned { entity: NetId },                                        // 2
    Despawned { entity: NetId },                                      // 3
    Died { entity: NetId },                                           // 4
    Health { entity: NetId, health: u32, max_health: u32, dead: bool }, // 5
    Turn { active: Option<NetId>, round: u64 },                        // 6
    Receipt { epoch: [u8;16], lane: u8, seq: u64, processed_tick: u64,
              status: ReceiptStatus },                                // 7
}
// v1 has no transform op; spatial replication waits for lane-1 movement.
// No open component bag. Undisclosed fields are omitted, never zero-filled.
// Despawned is sent only when disclosable per E017 A2/B2; otherwise EntityLeave.

#[derive(Clone, Copy, PartialEq, Eq)]
pub enum ReceiptStatus {
    Applied,                 // 0 — includes legal failed attacks and EndTurn
    Rejected(RejectionCode), // 1 + code
}

#[derive(Clone, Copy, PartialEq, Eq)]
#[repr(u8)]
pub enum RejectionCode {
    FrameTooLarge = 1, QueueFull = 2, UnsupportedVersion = 3,
    WrongDirection = 4, UnknownMessage = 5, Malformed = 6,
    LimitExceeded = 7, RateLimited = 8, Unauthenticated = 9,
    SessionExpired = 10, SeqConflict = 11, SeqGap = 12, StaleSeq = 13,
    SeqExhausted = 14, StaleTick = 15, FutureTick = 16,
    NotAuthorized = 17, IllegalAction = 18, ServerBusy = 19,
    SnapshotExpired = 20,
}
// Wire numeric values frozen in v1. New codes require a protocol version bump.

// crates/crpg-net/src/codec.rs
pub enum CodecError { FrameTooLarge, UnsupportedVersion, WrongDirection,
    UnknownMessage, Malformed, LimitExceeded }
pub fn encode_intent(frame: &IntentFrame) -> Result<Vec<u8>, CodecError>;
pub fn decode_intent(bytes: &[u8]) -> Result<IntentFrame, CodecError>;
pub fn encode_delta(frame: &DeltaFrame) -> Result<Vec<u8>, CodecError>;
pub fn decode_delta(bytes: &[u8]) -> Result<DeltaFrame, CodecError>;
// Byte limits enforced before allocation from hostile lengths; complete decode
// with no trailing bytes (take_from_bytes + empty-remainder check); unknown
// version/discriminant/lane rejected; NetId 0 rejected as Malformed.

// crates/crpg-net/src/transport.rs
pub trait Transport {
    type Error;
    fn send(&mut self, bytes: &[u8]) -> Result<(), Self::Error>;
    fn recv(&mut self) -> Option<Vec<u8>>;
    // Bounded, in-memory semantics specified in T018b. No threads, clock, I/O.
}
// E003-B: local to net. No contracts trait introduced or implemented here.
```

Operational policy defaults (host-supplied, tightening-only, not wire;
T018b enforces, T018c proves):
40 intent frames/s burst 80 and 64 KiB/s burst 128 KiB per authenticated peer;
failure responses 10/s burst 10 and 4 KiB/s burst 4 KiB; ingress 128 frames
AND 256 KiB per peer, host total 1,024 frames AND 2 MiB; egress 128 frames
AND 2 MiB per peer, host total 16 MiB; retry cache 256 receipts + canonical
intents per peer per lane ≤2 MiB; proof population 8 peers; snapshot
reassembly 1 in flight, ≤32 chunks, 5 s deadline; observed-tick window
`[server_tick.saturating_sub(200), server_tick]`. Retries and invalid attempts
count toward ingress. Rate time is host monotonic/injected, never World tick.

## Behaviour

- Encode is canonical and bounded: pre-check `bytes.len()` against the frame
  cap, post-check encoded length, never reserve from untrusted lengths.
- Decode order: length cap → version → lane/direction → discriminant →
  lengths/collection bounds → complete decode → trailing-byte check →
  semantic value checks (nonzero ids, seq range, ops length). First failure
  wins with the `CodecError` above. Codec never touches World/RNG/events.
- v1 freezes tags, field order, and numeric codes. Additive variants, field
  additions, or meaning changes require a new protocol version + new
  fixtures. v1 never ignores-and-continues on unknown input.
- NetId mapping discipline (for T018b/c drivers): keep whole `EntityId`
  including generation internally; never serialize raw arena ids; never reuse
  sim queue gaps as client seq; preserve relative `(Tick, sim_seq)` order when
  assigning `event_seq`. Revoked/hidden ids lose actionable mapping before new
  requests execute.
- No gameplay validation here beyond shape. `legal_actions` is not
  manufactured; `perform_action` precedence stays authoritative in sim.

## Test (all in `crates/crpg-net/tests/`, net-local, no testkit runtime dep)

1. Codec round-trip: every v1 variant through encode→decode identical;
   discriminant values pinned; Ulid canonical form pinned.
2. Rejection matrix: unknown version/discriminant/lane, trailing bytes,
   zero NetId, seq 0/MAX, empty/oversized ops, oversized frame/string/bytes —
   each maps to its exact `CodecError` with no allocation from hostile length.
3. Boundary: largest-valid / first-invalid frame, ops, string, collection,
   snapshot-chunk sizes. Encode bounds enforced as well as decode.
4. No-timing determinism: same frames in → same bytes out across runs on the
   same build; no HashMap iteration, no clock, no RNG in codec path.

Command that must pass: `cargo test -p crpg-net --test codec --locked`
