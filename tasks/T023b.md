# T023b — real QUIC host adapter (`crpg-server`)

## Task / Crate(s) / Purpose

Sole crate: `crpg-server`, selected in D02; Phase 4. **Blocked** on T022, completed
executable T023 and exact adapter approval (D02/D03/D04 selected; contract work
remains). Connect real endpoints
to the same authority used in-memory; do not put host execution in net.

## Interface

After T023, append exact bind/start/pump/shutdown/error API adapting its byte
endpoints to T022's authenticated session boundary. Pin ownership/threading,
monotonic clock conversion, queue budgets and credential handoff. No host
package or socket/runtime type is silently chosen by this contract.

## Behaviour

QUIC connections confer no gameplay identity until approved authentication
binds them. Real sockets feed the same admission, capture and checkpoint logic
as in-memory sessions. Preserve application seq/cache even when QUIC is
reliable; retry after a lost application receipt never executes twice.
Backpressure and shutdown release resources predictably without silently losing
committed receipts. No localhost, embedded or GM bypass. Native dedicated
adapters share one authority; process/filesystem policy stays above sim.

## Constraints

[Standing rules](POST-T018-RULES.md) apply. Sole host crate; net changes are a
separate child, Godot embedding is a later bridge task. New deps require approval.
NAT is independently chosen in D05 and only required for public reachability.

## Test

Public `host_quic` suite: two real headless clients fight through authenticated
transport, one malicious command leaves full state unchanged, lost receipt
retry executes once, slow client/close/shutdown tests, permitted views converge
against an independent oracle. Compare admitted schedules over real versus
in-memory adapters within the same native build. Corrupt/drop negative controls
must fail. Native Windows and Linux dedicated smoke is mandatory when binary
capability opens; embedded Windows smoke belongs to its separate bridge owner.

Commands (selected owner `crpg-server`):

```text
cargo test -p crpg-server --test host_quic --locked
cargo clippy -p crpg-server --all-targets --locked -- -D warnings
cargo test -p crpg-server --locked
```

Last is stopping command after common native gates.

## Downstream — 2026-10-04 (UTC): the `crpg-net-quic` split

From the user's Q12 decision and the [T023 re-contract](T023.md#re-contract--2026-10-04-utc-the-crpg-net-quic-crate).
This note is not approval of this task's adapter API, which is still to be
written.

- **Edge.**
  - T023b adds `crpg-net-quic = { path = "../crpg-net-quic" }` to
    `crpg-server`. `ALLOWED` already permits it (the `crpg-server` row is
    `None` minus godot/edit), and T023s adds a self-test for it.
  - T023b adds **no** quinn, quinn-proto, rustls or tokio edge, because
    `crpg-net-quic` exposes none of their types. D23's `crpg-server` grant

    own T018a-style record.
  - The `crates/crpg-server/AGENTS.md` sentence "QUIC crates, which D23
    approves only for T023b" is updated by T023b to name the path edge.
- **Graph.** `crpg-server`'s normal graph grows from 36 to **66**
  (Linux/GNU) and **68** (Windows/MSVC) packages, measured on 2026-10-04 in
  a throwaway copy (T023 R6). `crpg-net` and every crate that depends only
  on it stay at their current graphs.
- **Tests inherited from T023.** The five driver-based conformance cases of
  T023's earlier §13.3 run here instead (T023 R8.3), in `host_quic`, over
  real `crpg-net-quic` loopback against the T022 host:
  - malicious frames rejected without mutation;
  - filtered replica convergence against an independent oracle;
  - drop/corrupt negative controls that must fail;
  - lost-receipt retry executing once;
  - the admitted schedule over QUIC (including through an impairing UDP
    relay) equal to the in-memory schedule within the same native build.

  T023b may copy `UdpRelay` from `crpg-net-quic`'s `tests/support/` into
  its own `tests/support/`. That is test-only, and there is no shared
  runtime module and no testkit edge.
- **Mapping.** T023's E§7 mapping table (host ↔ `crpg_net_quic::QuicServer`)
  and revised questions 4 (fence by `SessionFenced` close) and 5 (hold one
  refused ingest frame) are this task's inputs, once answered.
- **Later lanes.** T024 (snapshot transfer), T025a (reconnect/resync) and
  T026p (movement lane) keep their wire, codec and reassembler work in
  `crpg-net`, which stays I/O-free. Any change to the real transport is a
  separate one-crate `crpg-net-quic` child, ordered before the host task
  that uses it:
  - a new QUIC stream or ALPN version for snapshots or control;
  - a resume hello;
  - enabling DATAGRAM frames for movement.

  The D23 dedup-patch vendoring for the first datagram lane attaches to
  `crpg-net-quic`'s graph. Host-side successors such as T025b consume
  those children through this adapter.
