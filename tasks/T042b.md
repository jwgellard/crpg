Notation (tests):
- `EPOCH` = `[0x01, 0x02, …, 0x10]` (16 bytes, byte `k` is `k + 1`).
- `ABILITY` = `Ulid::from_parts(0x0123_4567_89AB, 0x0CDE_F012_3456_789A)`
  (`crates/crpg-core/src/ulid.rs:27`), text `014D2PF2DB0000SQQG28T5CY4T` (26
  bytes, `:51–65`). `ABILITY_B` = `Ulid::from_parts(0x0123_4567_89AB,
  0x0CDE_F012_3456_789B)`, text `014D2PF2DB0000SQQG28T5CY4V` (one greater).
- `net(n)` = `NetId::new(n).unwrap()`; `tid(n)` = `TransferId::new(n).unwrap()`.
- `f` is a fixture's bytes; `m` is the mutated input of a row; `++` is
  concatenation; `u64::MAX` as a varint is `FF×9 01` (nine `0xFF`, then `0x01`),
  `u64::MAX - 1` is `FE FF×8 01`, `u32::MAX` is `FF×4 0F`; `×N` repeats the byte
  before it.
- **Row notation.** A row edits a fixture: `at·remove·bytes` replaces
  `f[at .. at + remove]` with `bytes` (hex; `-` is none); several edits are
  separated by `;`, ascending by `at`, each `at` an index into the unedited
  `f`. Everything of `f` outside the edited ranges is kept, so every bad byte
  has the fixture's full valid remainder after it and no truncation can mask
  it. Verdicts: `Accepted(m)` means the decoder accepts `m` and its canonical
  re-encoding is `m`; `Accepted(f)` means it accepts `m` and the canonical
  re-encoding is the fixture `f` (a non-canonical form, a case alias);
  a variant name means `Refused(that variant)`.

## Task

Give `crpg-net` the hostile-server mirror of T042a's malicious-client suite
(`tasks/T042.md`): the client's own decoders fed bytes a malicious server could
send, the same hostile classes, the same table-driven form, test-only. D67b
filed it "before players host games for each other (D65b)": today the server
is trusted and pinned by certificate, and each client decoder has only its own
suite's choice of bad inputs. Nothing treats them as one surface, none sends
one wire's frame to another wire's decoder, none corrupts every byte with every
value, and none checks that what a decoder accepts re-encodes stably (the
replica applies decoded values whole, `docs/adr/0035-client-replica.md:12`).

The surface is the ten decoders a server's bytes reach in `crpg-net`:
`codec::decode_delta` (`src/codec.rs:421`), `codec_v2::decode_delta`
(`src/codec_v2.rs:595`), `codec_v3::decode_delta` (`src/codec_v3.rs:1103`),
`codec_v4::decode_delta` (`src/codec_v4.rs:428`), `codec_transfer::decode_down`
(`src/codec_transfer.rs:246`), `transfer_v3::decode_down`
(`src/transfer_v3.rs:426`), `codec_resume::decode_down`
(`src/codec_resume.rs:205`), `movement_v4::decode_down`
(`src/movement_v4.rs:318`), and the two snapshot bodies
`codec_transfer::decode_body` (`src/codec_transfer.rs:97`) and
`transfer_v3::decode_body` (`src/transfer_v3.rs:258`). The delta decoders alone
read 23 op shapes; the suite fixtures every family of them (Health, Receipt,
ActionResolved, the v3 fact ops, the v4 movement ops), because the exhaustive
single-byte pass is only as wide as the frames it corrupts.

## Readings
Design decisions this contract makes. Each needs approval with the contract.
Each says which draft it follows.

1. **The surface is the ten client-side decoders; the QUIC `Welcome`, the
   client's close and the bridge's fault mapping are out.** A hostile server
   controls only the bytes it sends; the replica, the pools and `MoveOutbox`
   consume decoded values, they do not decode. `Welcome::decode`
   (`crates/crpg-net-quic/src/handshake.rs:343`), the QUIC client's close on a
   bad welcome (`crates/crpg-net-quic/src/client.rs:983`) and the Godot bridge
   step, which turns a decode failure into fault 52 and a replica refusal into
   53 (`crates/crpg-godot/src/core/client.rs:444–448`,
   `crates/crpg-godot/src/core/errors.rs:46–48`), are other crates; one task is
   one crate. *Follows:* both drafts (ten decoders; welcome/close/bridge
   indexed, not tested). *Departs:* both drafts fixtured one op per delta
   decoder (A: `EntityEnter`; B: an empty frame), which leaves `take_op`'s
   bodies, the largest hostile surface, to one random corpus; this contract
   fixtures every op family.
2. **Four parts.** See "Parts". *Departs from both drafts* (one part each),
   which cannot hold their own tables in ~500 lines.
3. **Hostile fields are an exact row table, not prose.** Each row is a named
   edit of a pinned fixture with the exact verdict computed from the code, and
   every row has the unmodified fixture as its one-field control (it is
   `Accepted(f)`), plus a nearer accepted row on the same field wherever a
   boundary exists (`c-1` beside `c-257`, `r-code20` beside `r-code21`).
   *Follows:* draft A's bound list as the idea; *departs* in making each bound a
   byte-exact row with a full valid remainder (both drafts gave counts and
   lengths in prose).
4. **Corruption is exhaustive; acceptance must be stable; one branch is wider
   than T042a's.** For every pinned frame every byte is replaced by every other
   value. The result must be a refusal other than `FrameTooLarge`, or
   `Accepted(m)`, or (inside ULID text only) the canonical alias re-encoding, or
   `Accepted(c)` with `c` **shorter** than `m` and `verdict(c) == Accepted(c)`.
   The fourth branch exists because `postcard` accepts non-minimal varints
   (postcard 1.1.3, `de/deserializer.rs` `try_take_varint_u32` and `_u64`:
   minimality is never checked) and, with the fixtures here, one corrupted
   byte reaches that leniency: setting `R`'s `max_health` high byte (index 9)
   to `0x00` reads `C8 00` as the value 72 in two bytes, and in the bodies
   (`Y81`, `Y82`) a corrupted varint byte can absorb a following `0x00` flag
   and re-align the rest into another valid, shorter frame. T042a's argument
   "no single-byte corruption reaches the leniency" does not carry over, and
   draft A's version of it is wrong for these fixtures. A mutant that makes a
   field lenient at the same length (a bool of 2 read as true, a `u32` that
   keeps bits above 32, a mode byte mapped to a neighbour) still fails: its
   `c` has the same length as `m` and is neither `m` nor a ULID alias.
   *Rejected:* `proptest` (a new dev-dependency; `AGENTS.md` "Do not add
   dependencies"); sampling in place of enumerating.
5. **Stability is checked through the encoder, not `PartialEq`.**
   `ResumeDown` holds a `ResumeProof`, which by trap never gains `PartialEq`
   (`src/protocol_resume.rs:94–97`, `AGENTS.md` of the crate); comparing
   re-encoded bytes works for all ten decoders. *Follows:* T042a Reading 6.
6. **Bodies are a second kind of subject.** `decode_body` has no version byte,
   no lane and no tag; its oversize error is `LimitExceeded`, not
   `FrameTooLarge` (`src/codec_transfer.rs:98–100`, `src/transfer_v3.rs:259–261`).
   The first-byte and lane matrices do not apply to them; the short-input,
   oversize, truncation, trailing, row, corruption and noise passes do.
   *Follows:* draft A (a `Body` kind) and draft B (bodies bare); *corrects* draft
   B's "a 2-byte body input is Malformed except `[0,0]` and over-bound counts",
   which is right only with the rule WC2 states.
7. **Stateless decoders have no replay, ownership, interest or flooding
   case.** A decoder is a function of one byte slice (T042a Reading 3). The
   client-side counterparts (the pools' admission gates, the replica's
   refusals) are receivers, proven in their own suites and out of scope.
   *Follows:* draft A Reading 3; draft B Reading 4.
8. **The "log line" at this level is the refusal's fixed `Display` text, which
   T042a's `refusal_texts_are_fixed` already pins** (`tests/malicious_client.rs:1579`)
   for the same `CodecError` type; it is not repeated. Writing a line, and the
   client's close (fault 52, `ProtocolViolation`), belong to the client
   programs (D67a). *Follows:* both drafts.
9. **A test of the suite's own "no panic" rule.** Every decode in every pass
   runs under the test harness's panic detection; a decoder panic fails the
   test. `reencoded` panics, with the input bytes, if an encoder refuses a
   value a decoder produced (that would be a decoder defect, S-1). *Follows:*
   T042a.
10. **T042b fixes nothing in a decoder.** If a case fails against unchanged
    `src/`, the implementer stops and reports it with the failing input
    (S-1). *Follows:* both drafts.

Errors found in the drafts and corrected here: draft A's W-8 says a `B81`
frame with tag `0x12` is `Malformed`; the code gives `UnknownMessage` (Begin's
`base_tick` byte `0x00` is the Cancel reason, and `0` is no reason,
`src/protocol_transfer.rs:196–202`, `src/codec_transfer.rs:377–378`); draft A's
claim that no single-byte corruption reaches varint leniency (Reading 4); draft
B's `B82` fixture was "pinned by the encoder at run time", which pins nothing;
here every fixture literal is pinned.

### The support module (T042b1 creates it; the other parts use it)
`tests/support/hostile.rs`, included by each suite file as
`#[path = "support/hostile.rs"] mod hostile;` (the pattern of
`tests/conformance.rs:13`). It starts with `#![allow(dead_code)]`, because each
suite uses a subset.

```rust
//! T042b: helpers shared by the hostile-server suites. No clock, no thread,
//! no I/O, no unseeded RNG, no `HashMap`/`HashSet`, no float.
use crpg_core::Ulid;
use crpg_net::codec::CodecError;
use crpg_net::protocol::NetId;
use crpg_net::protocol_transfer::TransferId;
use std::ops::Range;

pub const EPOCH: [u8; 16];          // 0x01 ..= 0x10
pub fn ability() -> Ulid;           // ABILITY
pub fn ability_b() -> Ulid;         // ABILITY_B
pub fn net(n: u64) -> NetId;        // NetId::new(n).unwrap()
pub fn tid(n: u64) -> TransferId;   // TransferId::new(n).unwrap()

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Verdict {
    /// The decoder refused the bytes with this error.
    Refused(CodecError),
    /// The decoder accepted them; the canonical re-encoding of the value.
    Accepted(Vec<u8>),
}

/// `Err(e)` is `Refused(e)`; `Ok(v)` is `Accepted(encode(&v))`. If `encode`
/// refuses a decoded value this panics with `who`, `bytes` (`{:02X?}`) and the
/// error: that is a decoder defect (Reading 9, S-1).
pub fn reencoded<T>(who: &str, bytes: &[u8], decoded: Result<T, CodecError>,
                    encode: fn(&T) -> Result<Vec<u8>, CodecError>) -> Verdict;

/// `bytes` with `bytes[at]` replaced by `value`; every other byte unchanged.
pub fn with_byte(bytes: &[u8], at: usize, value: u8) -> Vec<u8>;
/// `bytes` followed by `0x00` up to `len` (`len >= bytes.len()`).
pub fn padded(bytes: &[u8], len: usize) -> Vec<u8>;
/// The concatenation of `parts`, for literals.
pub fn cat(parts: &[&[u8]]) -> Vec<u8>;
/// Row edits (the "Row notation"): each `(at, remove, insert)` replaces
/// `bytes[at .. at + remove]` by `insert`. Panics if the edits are not
/// ascending by `at`, overlap, or reach past `bytes`.
pub fn edit(bytes: &[u8], edits: &[(usize, usize, &[u8])]) -> Vec<u8>;

/// What a row's mutated input must give.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Want { Refused(CodecError), Same /* Accepted(m) */, Orig /* Accepted(f) */ }

/// One named edit of one or more fixtures.
pub struct Row { pub id: &'static str, pub fixtures: Vec<&'static str>,
                 pub edits: Vec<(usize, usize, Vec<u8>)>, pub want: Want }
pub fn row(id: &'static str, fixtures: &[&'static str],
           edits: &[(usize, usize, &[u8])], want: Want) -> Row;
/// Asserts `got` against `row.want` for `original`/`mutated`; the message names
/// `who`, `row.id` and both byte strings (`{:02X?}`).
pub fn assert_row(who: &str, row: &Row, original: &[u8], mutated: &[u8], got: &Verdict);

/// Marsaglia xorshift64 (shifts 13, 7, 17), wrapping `u64` arithmetic:
/// `state ^= state << 13; state ^= state >> 7; state ^= state << 17;` then
/// returns the state.
pub struct XorShift64(pub u64);
impl XorShift64 { pub fn next(&mut self) -> u64; }
pub const SEED: u64 = 0x5EED_0000_0000_0042;

/// Rule of WA12: `Refused(_)`, or `Accepted(c)` with `verdict(&c) == Accepted(c)`.
pub fn stable(verdict: &dyn Fn(&[u8]) -> Verdict, bytes: &[u8]) -> bool;

#[derive(Debug, Default, Clone, Copy)]
pub struct Counts { pub refused: usize, pub exact: usize, pub alias: usize, pub shorter: usize }
/// Reading 4's rule over every index `i < original.len()` and every value
/// `v != original[i]`: with `m = with_byte(original, i, v)`, `verdict(&m)` is
/// (1) `Refused(e)` with `e != FrameTooLarge` (`refused`), or (2) `Accepted(m)`
/// (`exact`), or (3) `Accepted(c)` with `i` inside one of `ulid_text`,
/// `c.len() == m.len()` and `c[j] == m[j]` for every `j != i` (`alias`), or (4)
/// `Accepted(c)` with `c.len() < m.len()` and `verdict(&c) == Accepted(c)`
/// (`shorter`). Anything else panics with `who`, `i`, `v`, `m` and the verdict.
pub fn check_corruption(who: &str, verdict: &dyn Fn(&[u8]) -> Verdict,
                        original: &[u8], ulid_text: &[Range<usize>]) -> Counts;
```

## Behaviour
Normative. Each item names its tests. Every expected value below follows from
the cited code; the implementer does not adjust one to make a test pass (S-1).
Every verdict below was derived from the code at the cited lines and
cross-checked by the independent re-implementation named at the top.

Common facts, once (each decoder checks each field as it reads it and the
first failure wins; the order is the wire order, which each decoder's module
doc states):
- A **delta** decoder: whole-frame cap, then the version byte (the first read;
  an empty input fails it as `Malformed`), the lane byte at index 1
  (`WrongDirection`), `server_tick`, `event_seq` (both a `u64`, no range check,
  `src/codec.rs:434–435`), the op count (over 256 `LimitExceeded` before any op
  is read, `:436–439`), the ops in order, then trailing bytes (`Malformed`,
  `:445–447`). Every postcard failure (truncation, bad bool, bad varint, bad
  UTF-8) is `Malformed` (`:105–110`).
- A **downstream frame** (`0x81`, `0x82`, `0x91`, `0xA1`): cap, emptiness
  (explicit on `0x81`, `0x82`, `0x91`; the version read fails on `0xA1`), version
  (`UnsupportedVersion`), lane at index 1 (`WrongDirection`), then the tag or
  kind byte, then that tag's fields in order, then trailing bytes.
- A **body**: cap (`LimitExceeded`), the entity count (over 1,024
  `LimitExceeded`), the entities, the rest, then trailing bytes. No version, lane
  or tag.

WA1. **The fixtures.** Header `H(v)` = `[v, 0x00, 0x05, 0x01]` (version, lane 0,
`server_tick` 5, `event_seq` 1; the op count is at index 4). Each fixture, built
by its wire's encoder from its value, equals its literal, and
`verdict(f) == Accepted(f)` (each is canonical). `Dv`: the version's
`DeltaFrame { lane: 0, server_tick: 5, event_seq: 1, ops: [EntityEnter { entity:
net(9) }] }`, bytes `H(v) ++ [0x01, 0x00, 0x09]` (7 bytes, op tag at 5). `Rv`:
the same header with `ops: [Health { entity: net(9), health: 100, max_health:
200, dead: false }, Receipt { epoch: EPOCH, lane: 0, seq: 1, processed_tick: 41,
status: Rejected(NotAuthorized) }]`, bytes `H(v) ++ [0x02, 0x05, 0x09, 0x64,
0xC8, 0x01, 0x00, 0x07] ++ EPOCH ++ [0x00, 0x01, 0x29, 0x01, 0x11]` (33 bytes).
Table order: `D1, R1, D2, R2, D3, R3, D4, R4`. `R`'s indices: 4 op count; 5 Health
tag; 6 entity; 7 `health`; 8–9 `max_health` (`C8 01`); 10 `dead`; 11 Receipt tag;
12–27 epoch; 28 lane; 29 `seq`; 30 `processed_tick`; 31 status tag (`01`
Rejected); 32 code (`11` = 17, `NotAuthorized`, `src/protocol.rs:448–472`).
`R` has no ULID text (`ulid_text` empty). Layouts are the encoders'
(`src/codec.rs:395–414`, `:265–331`; `src/codec_v2.rs:567–586`, `:348–414`;
`src/codec_v3.rs:1077–1096`, `:789–924`; `src/codec_v4.rs:402–421`, `:278–304`).
*Tests:* HA1.

WA2. **Short inputs, exhaustively.** For every wire and every input of at most
two bytes (the empty input, all 256 one-byte inputs, all 65,536 two-byte
inputs): `[]` → `Malformed`; `[b]` → `Malformed` if `b` is the wire's first byte,
else `UnsupportedVersion`; `[b, c]` → `UnsupportedVersion` if `b` is not the
first byte, else `WrongDirection` if `c` is not 0, else `Malformed` (the
`server_tick` read fails). No input this short reaches the op count
(`src/codec.rs:426–435`, `src/codec_v2.rs:600–609`, `src/codec_v3.rs:1108–1117`,
`src/codec_v4.rs:433–442`). *Tests:* HA2.

WA3. **Oversize is refused first.** The cap of all four is 65,536
(`MAX_DELTA_FRAME_BYTES`, `src/protocol.rs:64`), checked before the version
(`src/codec.rs:422–424`, and each twin). Per wire: `[0xFF; 65537]` →
`FrameTooLarge` (the cap beats the version); `[0xFF; 65536]` →
`UnsupportedVersion`; for each of its fixtures, `padded(f, 65536)` →
`Malformed` (trailing bytes) and `padded(f, 65537)` → `FrameTooLarge`.
*Tests:* HA3.

WA4. **Every truncation is `Malformed`.** For every fixture and every `n < len`:
`verdict(&f[..n]) == Refused(Malformed)`. A prefix keeps the version, lane, header
and op count, so every check before the cut passes and the first read past the
end fails; a prefix cannot reach an over-bound count. *Tests:* HA4 (160
inputs).

WA5. **Trailing bytes are `Malformed`.** For every fixture, `f ++ [t]` for `t`
in `0x00, 0x01, 0xFF` → `Malformed` (24 inputs). *Tests:* HA5.

WA6. **A foreign first byte is `UnsupportedVersion`.** (a) Every fixture,
given to each of the other three wires → `UnsupportedVersion`. (b) Every
fixture with byte 0 replaced by each of the 255 other values →
`UnsupportedVersion` from its own wire. No negotiation or fallback
(`src/codec_v4.rs:4–8`). *Tests:* HA6.

WA7. **A foreign lane is `WrongDirection`.** Every fixture with byte 1 replaced
by each of the 255 values other than 0 → `WrongDirection`, checked right after the

## Decoder observations (not defects, not questions)
The code shows no decoder that cannot produce a safe error: every refusal is one of the
six `CodecError` variants, every decoded value re-encodes, and no read can panic or
allocate from an untrusted length (vectors grow by push; `take_bounded_str` and
`take_proof` bound a length before the bytes are examined). Three behaviours are
deliberate and are pinned by rows so a change is reviewed:
- a delta's `server_tick` and `event_seq` accept the full `u64` range, including `event_seq`
  0 (`src/codec_v2.rs:30–33`; rows `tick-u64max`, `evseq-0`, `evseq-u64max`);
- a decoded `health` may exceed `max_health`, and a `Moved` route is not checked against
  anything: the decoders check shape, not meaning (row `h-health-u32max`);
- `postcard` accepts non-minimal varints, and the decoders re-encode canonically (row
  `h-max-nonmin`, Reading 4). If `postcard` is ever bumped and that row changes, re-baseline
  it by review.
