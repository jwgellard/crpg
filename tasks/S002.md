## Task
Move the exact `rustls` pin in `crpg-net-quic` from =0.23.45 to =0.23.46, so
`cargo deny check` passes again.

## Crate(s)
`crpg-net-quic`, plus the `Cargo.lock` line it implies. The crate's
`AGENTS.md` pin line follows the manifest. No other crate changes.

## Purpose
RUSTSEC-2026-0346, -0347, -0348 and -0349, published after PR #28 merged,
affect `rustls` 0.23.45, and `deny` fails on every PR, `master` included.
0.23.46 fixes all four. The user approved the bump as D28i
(`tasks/DECISIONS-2026-10-16.md`, on PR #29), which supersedes only the
`rustls` line of D23. The same move was made once before, from 0.23.40 to
0.23.45 for RUSTSEC-2026-0285 (`docs/reviews/T030-quinn/README.md`).

## Change
- `crates/crpg-net-quic/Cargo.toml`: `rustls = { version = "=0.23.46", ... }`,
  same features (`ring`, `std`), default features off.
- `Cargo.lock`: `cargo update -p rustls --precise 0.23.46`. Only the `rustls`
  version and checksum change; no package is added or removed.
- `crates/crpg-net-quic/AGENTS.md`: the pin line.
