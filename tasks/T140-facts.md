# T140 facts — next `crpg-net` protocol version (ADR-0029 N1–N4)

## Requirements

- ADR-0029 §4 N1 facts: `World` facts (hashed) — mode, pending mode, round, clock (RT), timeline order with keys, active combatant (TB), pool `current`/`max` per pool id, attached effects with expiry round, standing orders, stat values; host facts (not hashed) — paused and reason, the viewer's own pause rights, auto-pause toggles, server tick, turn-timer deadline; events `RoundStarted`, `ModeChanged`, `OrderEnded`; intents `DeclareAction`, `EndTurn`, `Stop`, `Pause`, `Unpause`, `RequestMode` (`docs/adr/0029-kernel-range-and-time-model.md:324-331`).
- ADR-0029 §4 N2 disclosure: every new fact passes per-field grants of T027b (H-filter); standing orders default to the controlling peer only; rolls, DCs and margins stay off the wire unless Open question 8 opens them (`docs/adr/0029-kernel-range-and-time-model.md:333-336`).
- ADR-0029 §4 N3: one protocol version adds all of N1 after T024's version; v1, v2 and T024 stay frozen; T024 proceeds unchanged; the same version extends ADR-0028's snapshot allowlist (`docs/adr/0029-kernel-range-and-time-model.md:338-340`).
- ADR-0029 §4 N4 clock heartbeat: host sends `Clock { server_tick, paused }` when pause changes and at a policy interval while ticking (`docs/adr/0029-kernel-range-and-time-model.md:342-345`).
- ADR-0029 §4 N5: history gains `RoundStarted`, `ModeChanged`, `OrderEnded`; `HISTORY_VERSION` becomes 2, with new per-target history goldens; v1 journal and goldens stay readable and unchanged (`docs/adr/0029-kernel-range-and-time-model.md:347-349`).
- ADR-0029 follow-on table row 7: T140, `crpg-net`, next protocol version, N1–N4 facts, events, intents, snapshot allowlist; depends on T024, T027b, T138 (`docs/adr/0029-kernel-range-and-time-model.md:486`).
- ADR-0029 follow-on table row 8: T141, `crpg-server`, P1–P9, mode requests, projection of the new facts, heartbeat; depends on T138, T140 (`docs/adr/0029-kernel-range-and-time-model.md:487`).
- Open question 8 roll transparency: a ruleset may opt in to disclosing an actor's own raw roll and modifiers to its controller; DCs stay hidden unless the ruleset marks them public; H-filter decision in Follow-on 7 (`docs/adr/0029-kernel-range-and-time-model.md:515-519`).
