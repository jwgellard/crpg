## Snapshot and interest projection today

- T024 snapshot transfer: `SnapshotBody { entities: Vec<SnapshotEntity>, turn: Option<TurnFact> }` (`crates/crpg-net/src/protocol_transfer.rs:278-283`); `SnapshotEntity { entity: NetId, health: Option<HealthFact> }` (`crates/crpg-net/src/protocol_transfer.rs:285-292`); `HealthFact { health, max_health, dead }` (`crates/crpg-net/src/protocol_transfer.rs:294-303`); `TurnFact { active: Option<NetId>, round: u64 }` (`crates/crpg-net/src/protocol_transfer.rs:305-312`). Allowlisted facts today: presence, health/max/dead, turn (`tasks/T024.md:170-171`).
- T024 host sender rules: transfer ids strictly increasing per epoch from 1, never reused; `event_seq` never resets within an epoch; snapshot cursor is last `event_seq` issued before capture; later deltas above it; body holds only facts granted at capture (presence makes entity, health grant adds health, turn_state grant adds turn, active None unless present) (`docs/adr/0028-snapshot-transfer-subprotocol.md:25-35`).
- T027b interest projection: `InterestView` per session epoch, one viewer in exactly one area; host supplies `ViewerContext` (epoch, authoritative tick, viewer area, per-row `FieldMask` grants and health values, despawn keys, turn fact and its grant, two resend flags) (`docs/architecture/crpg-net.md:437-441`).
- Grants: `FieldMask { presence: bool, health: bool }`, default denies all (`crates/crpg-net/src/interest.rs:39-46`); `EntityFact { key, fields, health, resend_health }` (`crates/crpg-net/src/interest.rs:48-59`); `TurnState { area, active, round }` and `turn_granted: bool` (`crates/crpg-net/src/interest.rs:61-91`).
- `StateProjection { ops, enters, cursor }` (`crates/crpg-net/src/interest.rs:105-115`), `SnapshotProjection` (`crates/crpg-net/src/interest.rs:116-121`); `project_delta` returns enters, then `Health` per visible key, then at most one `Turn`, then removals; at most `MAX_PAGE_OPS` (`docs/architecture/crpg-net.md:464-470`).
- Retirement: entering keys take `next_id` upward once; removed key's mapping gone on return; no grave table (`docs/architecture/crpg-net.md:472-477`).
- Errors: `WrongEpoch`, `TooManyFacts`, `DuplicateFact`, `IdExhausted` (`docs/architecture/crpg-net.md:489-493`).
- Where mode, round, clock, timeline, pools, effects, orders live in `crpg-sim`: `CombatState.mode`, `pending_mode`, `clock: Option<EncounterClock> { round_ticks, elapsed }`, `round: u32`, `active: Option<EntityId>`, `pending_joins` (`crates/crpg-sim/src/combat.rs:833-856`); `Combatant.order: Option<StandingOrder { ability, target, repeat }>` (`crates/crpg-sim/src/combat.rs:219-221`, `:95-104`); pools `action_pool: ResourcePool { id, max, current, refresh, refill }` and `extra_pools` (`crates/crpg-sim/src/combat.rs:212-215`, `crates/crpg-rules/src/resource.rs:78-87`); attached effects `attached: Vec<AttachedEffect { effect, expires_round }>` (`crates/crpg-sim/src/combat.rs:216-218`, `:191-198`); timeline `Timeline` (`crates/crpg-sim/src/world.rs:1164-1167`); `World::combat()` accessor (`crates/crpg-sim/src/world.rs:1238-1241`); `World::tick()` (`crates/crpg-sim/src/world.rs:1134-1137`); `World::creatures()` (`crates/crpg-sim/src/world.rs:1206-1209`); `Combatant.attributes`, `health`, `max_health`, `dead`, `tags`, `fixed` (`crates/crpg-sim/src/combat.rs:205-234`).
