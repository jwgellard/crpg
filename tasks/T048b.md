# T048b — client proxy height and per-side colour (contract draft)

Status: **draft for Claude manager review and user approval**. This amends only
T048's `SceneSync.gd` proxy-placement and appearance rules; it is not approval
to implement or to edit T048's contract/tests.

## Exact contract

### Decision

T048 currently places the proxy node at `Vector3(3.0 * side_index, 0.0,
1.5 * rank)` and creates an origin-centred capsule of height 1.2 for side index
0, or box of height 1.0 otherwise (`apps/client/scripts/SceneSync.gd:55,97-106`).
`Main.tscn`'s ground plane is at its origin and has no assigned material;
the arena environment and directional light are configured at
`apps/client/scenes/Main.tscn:7-15,23-30`. Thus half the mesh extends below the
ground, while alive proxies have no side-specific surface colour.
**D44b (a) is chosen: lift only the `Mesh` child, not the proxy node**
(`tasks/DECISIONS-D44.md:18`).

1. **B13 — Grounded mesh placement.** Retain T048's proxy position rule
   unchanged: `proxy.position == Vector3(3.0 * float(side_index), 0.0,
   1.5 * float(rank))` (`apps/client/scripts/SceneSync.gd:55`). The lift is
   applied to the `Mesh` child only: `mesh.position.y = mesh_height / 2.0`,
   where `mesh_height` is read from the mesh resource already assigned for this
   row by `_set_mesh` — `CapsuleMesh.height` (1.2, so mesh `y == 0.6`) for side
   index 0, and `BoxMesh.size.y` (1.0, so mesh `y == 0.5`) for every other side
   (`apps/client/scripts/SceneSync.gd:97-106`). The proxy's `position.y` stays
   0.0. The mesh's bottom therefore rests at world `y == 0` (proxy `y == 0`
   plus the mesh's local lower extent `mesh_height / 2 - mesh_height / 2 == 0`).
   Side order, rank, mesh dimensions, `x`, and `z` retain T048 D7
   (`tasks/T048.md:81-93`).

2. **B14 — Side surface colour.** Add a private four-entry `SIDE_COLORS`
   palette in `SceneSync.gd`, indexed by T048's stable side index. Exact opaque
   RGBA values:

   | Side index | Colour |
   |---:|---|
   | 0 | `Color(0.20, 0.60, 1.00, 1.00)` |
   | 1 | `Color(1.00, 0.35, 0.20, 1.00)` |
   | 2 | `Color(0.25, 0.85, 0.45, 1.00)` |
   | 3 | `Color(0.75, 0.45, 0.95, 1.00)` |

   For `side_index >= SIDE_COLORS.size()`, use
   `SIDE_COLORS[side_index % SIDE_COLORS.size()]` (deterministic palette wrap).
   Install a `StandardMaterial3D` with that albedo as a surface override on the
   proxy's `Mesh` child, not as `material_override`. T048 reserves
   `Mesh.material_override` for the dead tint (`tasks/T048.md:94-107`): while
   alive it remains `null`; while dead the grey override takes precedence over
   the side surface material; clearing dead restores the side colour without
   replacing the proxy. Update the surface material whenever the row's side
   index changes, including a kept row changing sides.

3. **B15 — Dead precedence and reversibility.** Preserve T048 D8 exactly:
   every nonzero `dead[i]` leaves the row in place, sets the `Mesh` child's
   `material_override` to `StandardMaterial3D` with
   `albedo_color == Color(0.35, 0.35, 0.35)`, and sets `Label.modulate` to the
   same tint. A living row has `material_override == null` and white label
   modulation. The dead override wins visually over B14's side surface
   material; the underlying side material remains assigned and is visible again
   after revival. No label suffix, hiding, or despawn is added
   (`tasks/T048.md:94-107`).

4. **B16 — Label and lifecycle compatibility.** The label remains a separate
   `Label3D` child with local position `(0, 1.2, 0)` — set today at
   `apps/client/scripts/SceneSync.gd:83` (`label.position = Vector3(0.0, 1.2,
   0.0)`) — billboard enabled, and `text == names[i]`; proxy naming remains
   `proxy_<id>`. These are existing interface rules (`tasks/T048.md:157-163`).
   Because the lift moves only the `Mesh` child, the label's local offset is
   unchanged, and its world position lands at the mesh top (or just above): at
   the capsule's top (world `y == 0.6 + 0.6 == 1.2`) for side index 0, and 0.2
   above the box's top (world `y == 1.2` vs box top `0.5 + 0.5 == 1.0`) for
   every other side. Text, billboard, and the dead modulation rule do not
   change. T048's reconcile lists/order, child order, `clear()`, authority
   boundary, and all four permitted view getters remain unchanged (D1-D6,
   D9-D11 and B1-B5/B9-B11: `tasks/T048.md:24-80,108-112,194-235`).

### Tests

Keep T048's S1-S14 suite and runner (`tasks/T048.md:165-189,243-267`). Add
these numbered cases to the existing case file and runner; each case returns
`"PASS"` only on success, following the approved sentinel correction
(`tasks/T048.md:408-420`). Tests compare exact `Vector3`/`Color` values except
mesh resource dimensions, which use `is_equal_approx` as the T048 completion
record documents (`tasks/T048-completion.md:45-49`).

| Case | Required exact assertions |
|---|---|
| **S15 — Ground lift** (B13) | Sync a capsule-side row and a box-side row. Assert proxy positions `(0, 0, 0)` and `(3, 0, 0)` respectively (T048's rule unchanged); each `Mesh.position == Vector3(0, 0.6, 0)` for the capsule and `Vector3(0, 0.5, 0)` for the box (the lift is on the mesh, not the proxy); capsule `.height` approximately `1.2`, box `.size.y` approximately `1.0`; and each mesh's `position.y` equals half its height so the mesh's lower extent rests at proxy-local `y == 0`, i.e. world `y == 0.0`. Also assert the box row at rank 1 has proxy `(3, 0, 1.5)` and mesh `(0, 0.5, 0)`. |
| **S16 — Palette and wrap** (B14) | In one sync, use five first-seen sides at indexes 0–4. Assert each `Mesh` child's surface-0 material is a `StandardMaterial3D`, its albedo equals the table's exact colour for indexes 0–3, and index 4 equals index 0 by the modulo rule. Assert all five proxies have `material_override == null`, and retain the palette colour after a repeated sync. |
| **S17 — Dead override wins, then restores** (B15) | For side indexes 0 and 1, record each surface material and its exact B14 albedo. Sync both rows dead (including a nonzero byte greater than 1): assert same proxy objects/count/positions, `material_override` is a `StandardMaterial3D` with exact grey albedo, label modulation is exact grey, and the surface material/albedo is still the recorded side colour. Sync alive: assert override is null, label is white, and the original side surface colour is visible again. |
| **S18 — Lift does not alter label-local contract** (B16) | For capsule and box rows, assert `Label.position == Vector3(0, 1.2, 0)`, billboard is `BaseMaterial3D.BILLBOARD_ENABLED`, and text exactly matches the view after spawn, side change, and repeated sync. Assert alive label modulation is white; with dead set, it is grey and text/position/billboard are unchanged. Also assert names remain exactly `proxy_<id>`. |

No existing case changes. Because B13 lifts only the `Mesh` child and leaves the
proxy node at T048's position, none of S1–S14's hard-coded proxy positions,
object-identity or layout assertions changes, and no "needs user approval" edit
is required. S6 and S12 compare positions captured at runtime rather than
asserting a hard-coded `y`; both remain valid as-is.
