## Decisions (binding for this contract; reviewable, no waiver granted)

1. **Additive generic schemas; srd-lite pins content.** Schemas stay
   count-agnostic (any pool/ability/modifier counts in range, all outcome
   labels, both defense kinds, both effect aims); the srd-lite *content*
   pins two pools, two abilities, two bands-plus-natural vs two bands, one
   effect, duration 2. Counts are content tests, never validation. A third
   ruleset extends content (or migrates schemas) without touching logic.
2. **No wire change to existing families except the two version bumps.**
   `Creature.stats` stays `BTreeMap<String, Fx16_16>`; existing fixtures
   keep their meaning. `crpg.ruleset/1` and `crpg.ability/1` bytes are
   read-only history — `/2` documents carry the new shapes.
3. **Primary-pool cost convention (migration-safe).** `Ability.cost` is
   retained with a refined meaning — spend from the ruleset's first-listed
   (primary) pool — plus new `extra_costs: Vec<AbilityCost{pool: Ulid,
   amount: u32}>` for all other pools. Rationale: per-type migration
   chains are context-free, so the `/1 → /2` edge cannot look up pool
   ULIDs; every `/2` default below is local (`cost` kept, `extra_costs`
   empty, `ends_turn: true`, `effect: None`, `defense: ActorAttribute`,
   `natural_die: None`). An ability must spend something: `cost > 0` or
   `extra_costs` nonempty with every amount `>= 1`, each entry within its
   pool maximum (else `invalid_cost`). If the migration framework is found
   to support cross-document context cleanly, this task still ships the
   convention above — a second cost shape is not authorized here.
4. **Effect-scoped stacking policy.** Each effect declares one `mod_type`
   name and one `policy` governing all its modifiers; every modifier in
   the effect shares that `mod_type`. No ruleset-global policy table, no
   cross-effect policy conflict surface. `mod_type` nonempty; modifiers
   nonempty with unique modifier ULIDs.
5. **Self-contained fixture, empty package requires.** `combat_srd`
   embeds its ruleset/ability/table/effect documents (same ULIDs as the
   canonical source) and declares no package requirements, mirroring
   T016a decision 5, so gate 8 stays standalone. `Ruleset.package`
   (`srd-lite`) and `version` (`0.1.0`) self-identify the ruleset.
6. **Orphan effects allowed but unchecked.** Per-owning-ruleset checks
   (attribute/cost/defense/policy coverage) run for abilities a ruleset
   lists; an effect listed by no ability keeps only its generic table/pool
   reference checks. Minimal content has no orphans (tested).
7. **Dice-count bounds stay sim-side.** Data stores dice notation only
   (T016a); `natural_die` index validity against the parsed count is B3's
   check, not data's. Data validates `natural_die` is well-formed `u32`
   only.
8. **No new dependencies, no ADR, no downstream authorization.** This task
   follows the T010/T011a/T012a/T016a data-owned precedent. B3 still needs
   its own reviewed ADR; nothing here grants it.

## Interface (exact public shapes; re-export at the crate root)

New module items in `combat.rs`. All public items have rustdoc. Ordered
collections and integer/core values only; no floats, hash maps, OS
branches, clocks, or id generation. New `ObjectKind` variant `Effect`
(declared after `Encounter`).

```rust
pub enum DefenseWire {
    ActorAttribute,
    TargetStat { stat: String },
}

pub struct AbilityCost {
    pub pool: Ulid,
    pub amount: u32,
}

pub enum EffectAimWire { Slf, Target }

pub enum EffectTargetWire { Roll, Dc }

pub enum EffectOpWire { Add, Set }

pub enum PolicyWire {
    StackAll,
    HighestBonusWorstPenalty,
    HighestPriorityPerName,
}

pub struct EffectModifierWire {
    pub id: Ulid,
    pub target: EffectTargetWire,
    pub op: EffectOpWire,
    pub value: i32,
    pub priority: i16,
    pub name: Option<String>,
}

pub struct Effect {
    pub id: Ulid,
    pub slug: String,
    pub name: String,
    pub note: Option<String>,
    pub aim: EffectAimWire,
    pub mod_type: String,
    pub policy: PolicyWire,
    pub modifiers: Vec<EffectModifierWire>,
    pub duration_rounds: u32,
}
```

Changed shapes (all other fields keep their T016a meaning, order, and
serde rules):

```rust
pub struct ActionPoolTemplate { /* unchanged: id, max, refresh */ }

pub struct Ruleset {
    // ... id/slug/name/note/package/version/stats/health_stat/attributes ...
    pub pools: Vec<ActionPoolTemplate>, // was: action_pool: ActionPoolTemplate
    // ... abilities: Vec<Ulid> ...
}

pub struct Ability {
    // ... id/slug/name/note/dice/attribute/outcome_table/damage ...
    pub cost: u32,                    // retained: spend from pools[0]
    pub extra_costs: Vec<AbilityCost>,
    pub ends_turn: bool,
    pub effect: Option<Ulid>,
    pub defense: DefenseWire,
    pub natural_die: Option<u32>,
    // ... requires_target/allow_self_target ...
}
```

Serde: structs `deny_unknown_fields`; `_note`/`effect`/`natural_die`
optional-missing, other nullable fields required-nullable with matching
schema annotations; `DefenseWire`, `EffectAimWire`, `EffectTargetWire`,
`EffectOpWire`, `PolicyWire` mirror the T015 adjacent `type`/`value`
snake-case shapes with hand-written `Deserialize` impls enforcing exact key
sets per variant (the unit-variant unknown-field trap from T016a —
`ActorAttribute`, `Slf`/`Target`, `Roll`/`Dc`, `Add`/`Set`, and the three
policies all keep manual impls plus unknown-field tests). `Serialize` /
`JsonSchema` stay derived. Stat references are strings, table/pool/effect/
ruleset/ability/encounter identities are ULIDs.

`Document` gains `Effect(Effect)` (`crpg.effect/1`); `Ruleset` and
`Ability` tags move to `/2`.
